# 方案进度总结（2026-10-13）

---

## 一、技术方案流程（方案书 §3.1）

整条链路如下，可据此快速回忆方案全貌：

```
中信交付数据（800股×3年行情 + 32条指数）
  │
  ▼ ETL（src/qgbs/data/etl_zx.py → data_store/）
金融特征构建（趋势/反转/波动/流动性 + 市场状态，共 26 维）
  │
  ├─────────────────────────────────────┐
  ▼                                     ▼
经典特征 x                     GBS 编码：特征→模式地址（QuantileEncoder）
  │                                     ▼
  │                          GBS 采样（真机 / 仿真 / 缓存样本库）
  │                                     ▼
  │                          GBS 特征服务：边际 / 二阶联合 / 高阶基三族特征 φ_GBS
  │                                     │
  └────────────── 拼接 ψ = [x; φ_GBS] ◄─┘
                          ▼
              经典读出模型（Ridge / GBM）预测 alpha
                          ▼
              稳定化：ρ 收缩混合 + ν 不确定性折扣
                          ▼
              风险模型（Ledoit–Wolf 收缩 / 因子风险）
                          ▼
              cvxpy 稳健均值-方差优化
              max αᵀw − κwᵀΣw − τ‖Δw‖₁ − γ‖w‖²
              （含权重上限、现金区间、暴露约束、交易成本）
                          ▼
              滚动样本外回测 → IC/ICIR/Sharpe/回撤/换手
                          ▼
              统计推断：分块 bootstrap CI、Deflated Sharpe、White Reality Check
```

三条贯穿全局的设计原则：

1. **防泄漏**：每一层都是"训练期 fit → 冻结 → 测试期只读"，码本、因子模型、特征筛选无一例外；
2. **对照矩阵**：C0–C5 经典对照（含两种安慰剂 C4/C5），Q1–Q4 递进加入 GBS 边际→二阶→高阶→非线性读出；
3. **递进假设 H1→H4 + 停止规则**：任一层不过就停止扩复杂度、如实报负结果；物理归因条款要求 GBS 必须不差于匹配低阶统计的经典随机特征，否则增量不能归功于量子结构。

## 二、数据

### 2.1 中信方数据（方案书 §九）

中信首批交付经 ETL 入库至 `data_store/`（727 交易日 × 800 股，区间 2023-01-03 ~ 2025-12-31）：

| 文件 | 内容 | 实验中的用途 |
|---|---|---|
| asset_pool.csv | 800 股 + 中信一二级行业（zz800 池） | 资产池定义；行业映射（标签中性化与行业相对特征） |
| daily_market.csv | 复权收盘、成交量、成交额、换手率、总市值/流通市值 | 26 维金融特征的全部原始字段 |
| trading_status.csv | 停牌、可买/可卖、ST 标记、上市日期 | 可交易性过滤；is_st / list_age 特征 |
| market_sector_factor.csv | 32 条市场/行业指数日收益 | alpha 标签的市场+行业中性化（JointFactorModel）；行业相对特征的行业基准 |
| constraints_costs.csv | 佣金/印花税/滑点/现金区间 | 目前仅做占位值，组合层按假设成本口径，不作结论性产出 |

**26 维特征体系（现行正式标准）的构成**：全部由上述字段经滚动因果变换构造（窗口 warmup 出 NaN，未来信息不进入历史特征值）——

- 动量/反转（5）：mom_5、mom_20、mom_60、mom_120、rev_5
- 波动与形态（5）：vol_20、vol_60、skew_20、kurt_20、downside_vol_20
- 回撤（2）：mdd_20、mdd_60
- 量价流动性（4）：amount_mean_20、amihud_20、volume_abnormal_20、turnover_vol_20
- 市场状态（4，按日期广播）：mkt_vol_20、mkt_corr_20、mkt_disp_20、mkt_breadth
- 市值规模（1）：mv_log = log(流通市值)
- 行业相对（3）：ind_rel_mom_20、ind_rel_rev_5、ind_rel_vol_20（个股量 − 本行业指数同窗口量）
- 状态/股龄（2）：is_st、list_age = log1p(上市天数)

### 2.2 GBS 真机数据

**数据本体**：一批黑盒交付的真机采样——5,000,000 shots × 8176 模式（511 时间模式 × 16 空间模式，与"九章4.0"装置同构），np.packbits 位压缩，平均 2210.6 点击/shot。已入库 `sample_store/hardware/hw-5M-b0/`。实验使用口径：200k shots、分箱 b=255 满覆盖、identity 模式映射。

**使用方式（三族特征的获得过程）**：

1. **编码**：每只股票每个调仓日的 26 维特征，经训练期拟合的截面分位数变换（QuantileEncoder）映射为模式地址——特征 j 的取值分位数决定时间模式编号，特征序号经模式映射决定空间模式。每个样本点（日期×股票）由此得到 26 个模式地址；
2. **边际特征（Q1 族）**：统计真机样本在**单个**被寻址模式上的点击频率，经激活函数后作为特征——物理含义是装置点击剖面在该地址处的取值；
3. **二阶联合特征（Q2 族）**：统计被寻址**模式对**的联合点击频率/关联——两个特征对应模式的共同激发强度，携带模式间联合结构信息；
4. **高阶特征（Q3 族）**：用两步法（n₁=1000、n₂=2000、保留 N_B=3000）筛选高频计算基，统计样本落在这些多模式联合 bit 模式上的频次——携带局部高阶交互信息。

三族特征与 26 维经典特征拼接后进入读出模型。

## 三、读出、风险与组合优化模型（方案书 §5.3 / §6）

此处仅列出现状，公式详见方案书对应章节。

**读出模型（§5.3）**：
- **Ridge 岭回归**：闭式解含正则项 λ（alpha 在 {0.1, 1.0, 10.0} 网格内经验证期选择）；已实现并用于全部正式实验；
- **GBM 梯度提升树**：默认配置（100 棵 / 深度 3 / 学习率 0.1）；已实现并用于全部正式实验；
- 稳定化机制（§5.4）：ρ 收缩混合（经典预测与 GBS 增强预测的配权，验证期选择）与 ν 不确定性折扣均已实现；当前协议下 ν 保持 0、robust-ρ 口径已实现但不进默认链路。

**风险模型（§6.1）**：Ledoit–Wolf 收缩协方差与因子风险模型均已实现；任何风险矩阵进入优化器前完成三步处理——对称化、负特征值截断（最近半正定投影）、尺度校准。GBS 风险先验（条件波动率/相似性）为方案书预留分支，未启用。

**组合优化（§6.2）**：cvxpy 稳健均值-方差优化已实现运行，目标函数 max αᵀw − κwᵀΣw − τ‖Δw‖₁ − γ‖w‖²，约束含权重上限、现金区间、行业/风格暴露区间与交易成本（当前为占位成本口径）。超参 (κ,τ,γ) 训练/验证期选择、测试期冻结。

### 4.2 统计口径与判定规则

- **显著性口径**：配对逐日 rank IC 差 + 分块 bootstrap 置信区间（2000 次、块长 5、种子 42）；同一测试期、同一协议下两两配对。
- **判定规则**（§7.5）：**H1** = Q1 相对 C2 的 rank IC 增量 CI 下界 > 0；**H2** = Q2 相对 Q1 显著为正；**H3** = Q3 相对 Q2 显著为正；**H4** = Q4 扣成本组合效用相对经典基线显著为正；**归因条款** = Q 系须不差于匹配低阶统计的经典随机特征，否则增量不能归因于 GBS 联合结构。
- **防泄漏**：每折编码器/特征管线/中性化模型/读出模型仅用本折训练窗从零重训；标签为前瞻 21 日收益的市场+行业中性化 alpha。

### 4.3 已完成实验详述

**实验 1：26 维特征体系构建与质量验证**

- 内容：市值/行业相对/状态股龄三个特征族的实现 + 因果性与正确性测试 + 全量面板质量自检。
- 结果：zz800 面板 58.2 万行 × 26 维；覆盖率 96–99%；特征间无冗余（最大 |相关| 0.795 < 阈值 0.95）；因果性测试通过（扰动未来数据不改变历史特征值）；全套测试 274 passed。
- 产物：`artifacts/e44_input_boost/step1_feature_report.json`。

**实验 2：经典监督基线（C2 / C3）**

- 内容：26 维特征分别接岭回归（C2）与梯度提升树（C3），检验新特征体系下经典模型的兑现能力。
- 结果：C2 的 rank IC 为 -0.0163（ICIR -0.179，Sharpe 2.08）——线性读出兑现不出新信号；**C3 的 rank IC 达 +0.0352（ICIR +0.406，Sharpe 2.52，80% 折为正）——由负转正，为当前最强经典基线**。
- 结论：26 维体系的增量信号（市值/行业相对/股龄的交互形态）以**非线性形态**存在，需要非线性读出兑现。
- 产物：`artifacts/e44_input_boost/step2/`。

**实验 3：真机 GBS 边际特征增强（Q1）与 H1 判定**

- 内容：Q1 = 在 C2 的 26 维经典特征基础上拼接真机 GBS 边际特征（200k shots），同样接岭回归，与 C2 配对对比——两者唯一差别是 GBS 边际特征，差值即 GBS 特征的增量。
- **H1 判定结果：Q1 − C2 的 rank IC 增量 = +0.0332，95% CI [+0.0183, +0.0481]，下界 > 0 —— H1 显著成立（项目首个 H1 阳性，75% 折为正）**。Q1 自身 IC 由 C2 的 -0.0163 转正至 +0.0169。
- 机制解读：26 维新信号以非线性形态存在（实验 2 已证 ridge 兑现不出），GBS 编码器的分位数重编码把截面排名展开成线性可读的高维形式，恰好为岭回归补上了非线性变换——与参考论文（Gong et al., arXiv:2506.19707）"GBS 作为非线性展开层增强线性读出"的机制一致。
- 产物：`artifacts/e44_input_boost/step3/`。

**实验 4：归因检验（§7.5 归因条款）**

- 内容：判定 H1 的 +0.0332 是 GBS 特征的真实贡献，还是普通随机升维即可复现。构建经典对照（岭回归锁死、同协议同种子、仅用训练期数据拟合防泄漏）——**匹配随机特征对照**（方案书 §7.1 辅助诊断三）：以高斯 copula 生成与 GBS 特征面板逐列边际分布和协方差都匹配的等维随机特征（自身 rank IC -0.0184）。
- 结果：

| 对比 | ΔIC | 95% CI | 判定 |
|---|---|---|---|
| **Q1 − 匹配随机特征** | **+0.0353** | **[+0.0204, +0.0511]** | **通过归因条款**：Q1 显著跑赢匹配低阶统计的随机特征 |
| 匹配随机特征 − C2 | -0.0021 | [-0.0039, -0.0002] | 随机特征自身无增量（对照有效性确认） |

- 结论：Q1 相对匹配低阶统计的经典随机特征显著为正，且随机特征自身相对 C2 无增量——按方案书 §7.5 归因条款，**H1 增量确认归因于 GBS 特征，不能由普通随机升维解释**。
- 产物：`artifacts/e44_input_boost/step4_attribution/`。

### 4.5 当前结论快照（26 维正式口径）

1. **26 维特征体系下经典非线性基线表现良好**：C3 rank IC +0.0352、ICIR +0.406——当前最强配置；
2. **H1 首次成立**：Q1 相对 C2 的 rank IC 增量 +0.0332，CI 下界 > 0，机制为 GBS 编码器的分位数非线性升维兑现了线性读出无法触及的信号；
3. **归因确认**：Q1 显著跑赢匹配低阶统计的经典随机特征（+0.0353 [+0.0204, +0.0511]），通过 §7.5 归因条款——H1 增量确认由 GBS 特征带来，不能由普通随机升维解释；二阶/高阶层级（量子关联结构所在层级）的检验待 Q2/Q3 隔离复检完成；
4. **H4 待终判**：以验证期择优组合口径重做，全量堆叠参考口径不成立仅作参考；
5. **全部显著性为名义口径**，推断层复核后如有调整将如实更新。
