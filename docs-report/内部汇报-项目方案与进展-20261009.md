## 一、项目背景与目标

### 1.1 业务背景

中信现有业务场景：两个候选资产池（29 资产池 = 28 只股票 + 现金；100 资产池 = 99 只股票 + 现金），现有模型为经典 Markowitz 均值—方差配权，历史评估口径为 2025 年建模、2026 年 1—4 月观察绩效（历史参照值 2.36% / 10.47%）。

已知现象：大资产池没有自然转化为更好的样本外表现——通常与收益估计误差、协方差不稳定、权重集中、模型选择偏差共同相关。

### 1.2 项目目标（方案书 §1.2）

1. 建立可复现的真机 GBS 样本采集、标定与版本管理流程；
2. 将真机 GBS 多模式统计量封装为标准机器学习特征组件；
3. 在统一滚动样本外协议下，评估 GBS 特征相对经典基线的增量信息；
4. 将通过验证的预测接入稳健组合优化器，评估扣成本后的组合效用；
5. 形成可扩展到风险预测、资产筛选、深度融合模型的技术底座。

### 1.3 一句话原理

把每只股票在每个调仓日的金融特征"翻译"成 GBS 装置的模式地址，用真机（或仿真）采样样本库中这些地址的联合统计量（边际/二阶/高阶频率）作为**增强特征**，与原始特征拼接后训练读出模型，预测市场与行业中性化后的 alpha，再交给经典稳健优化器配权。

**核心赌注**：GBS 特征不带来新的金融信息，它是对原始特征的固定非线性变换。赌注在于真机采样分布的复杂联合结构（经典难模拟）能否把原始特征中"藏得深的交互关系"展开成模型可用的形式——这是经典随机升维便宜地造不出来的。整个对照实验设计都围绕"如何证明增益来自 GBS 独特结构而非随机升维假象"展开。

## 二、总体方案设计

### 2.1 技术架构（方案书 §3.1）

```text
真机 GBS 采样（固定干涉网络，离线）
      ▼
样本清洗、质量标定、批次与版本管理
      ▼
GBS 统计与特征服务（边际 / 二阶 / 经筛选的局部高阶）
      ▼
原始金融特征 ⊕ GBS 特征 → 经典读出模型（岭回归/GBM）
      ▼
预测 alpha、稳定化（ρ 收缩）与置信度评估
      ▼
收缩风险模型 + 经典稳健组合优化
      ▼
滚动样本外执行与绩效归因
```

### 2.2 递进假设与判定规则（§3.2、§7.5）

| 假设 | 内容 | 判定规则（测试期 + §7.4 统计口径） |
|---|---|---|
| H1 | 模式边际统计可作为非线性特征 | Q1 相对 C2 的 rank IC 增量 CI 下界 > 0 |
| H2 | 二阶联合统计含增量信息 | Q2 相对 Q1 增量显著为正，且显著优于置换对照 |
| H3 | 局部高阶模式表达条件交互 | Q3 相对 Q2 增量显著为正，高阶基通过跨批次稳定性筛选 |
| H4 | 预测增量转化为扣成本组合效用 | Q4 扣成本效用相对 C1/C3 显著为正，风险/换手/暴露约束全满足 |
| 物理归因 | 增量来自 GBS 联合结构而非随机升维 | Q 系不差于匹配低阶统计的经典随机特征对照 |

任何一层未通过即停止扩大复杂度，回退已验证最简配置，如实报告负结果。

### 2.3 对照矩阵（§7.1）

| 编号 | 配置 | 目的 |
|---|---|---|
| C0 | 原经典均值—方差流程 | 复现客户结果（待 baseline 数据） |
| C1 | 修正口径 + 收缩风险 + 稳健约束 | 可比经典基线 |
| C2 | 金融特征 + 岭回归 | 线性监督基线 |
| C3 | 金融特征 + 梯度提升树 | 经典非线性基线 |
| C4 | 分位数离散化 + 显式交互 | 安慰剂：检验编码方式本身贡献 |
| C5 | 等维随机特征 | 安慰剂：检验单纯升维贡献 |
| Q1 | + GBS 边际特征 | 检验单模式信息 |
| Q2 | Q1 + GBS 二阶联合 | 检验联合关联增量 |
| Q3 | Q2 + 经筛选局部高阶基 | 检验高阶交互增量 |
| Q4 | 最优 GBS 特征 + 非线性读出 | 完整增强配置 |

辅助诊断：① 真机 vs 仿真分布对照（P3）；② 置换对照（保边际、破坏联合）；③ 匹配低阶统计的经典随机特征对照；④ 映射与批次稳定性。

### 2.4 评估与统计口径（§7.2—§7.4）

- 滚动协议：定长训练窗（原则 2—3 年）+ 验证 3—6 月 + 测试逐月推进；purge（≥预测期限 h）+ embargo 隔离；
- 预测层指标：Spearman rank IC、ICIR、分层收益、方向准确率；
- 组合层指标：扣成本收益、Sharpe、Sortino、最大回撤、CVaR、换手、HHI、暴露合规；
- 统计推断：时间分块 bootstrap CI、Deflated Sharpe、White Reality Check、Benjamini–Hochberg 多重比较控制；显著性水平与判定阈值测试前锁定。

## 三、工程实现细节（六层链路现状）

全部代码位于 `src/qgbs/`，249 项自动化测试全部通过（截至 2026-09-28）。防泄漏是贯穿所有层的设计主线：每层均为"训练期 fit → freeze → 测试期只读"的状态机。

### 3.1 数据层（`data/`）

- `etl_zx.py`：中信交付 3 文件 → `data_store/` 7 个标准文件（asset_pool / daily_market / trading_status / market_sector_factor / constraints_costs / field_dict / MANIFEST），新数据交付可分钟级接入；
- 关键口径：**日收益 = 复权收盘 ÷ 复权前收 − 1**（交付前收价在除权日按新因子调整，全样本 772 个除权日，已固化处理）；一致复权价由收益连乘重构；成交量手→股、市值万元→元（交叉验证通过）；停牌/ST 标记推导；行业中文名映射中信行业指数代码；
- 现状缺口：`constraints_costs.csv` 为占位值（标注"禁止用于结论性产出"）；公司行动、baseline 结果未交付；资产池为中证800 的 2025 年末快照（非 PIT）；`store.py` 版本化存储仍为 stub。

### 3.2 因子层（`factors/`）

- `finance.py`：base 特征 11 个（5/20/60/120 日动量、5 日反转、20/60 日波动率、20 日偏度/峰度、成交额均值、Amihud 非流动性），全部因果 rolling 计算；extended 集（下行波动、回撤、量异常、换手率波动、市场状态四件套）已实现未启用（见 §5.4）；
- `neutralization.py`：联合因子模型（市场 = 中证800 + 中信一级行业指数），训练窗内逐股含截距 OLS 估 β̂；**标签 = 未来 21 日复利收益 − β̂ᵀ×同期因子复利收益**（截距不扣，留给模型学个股 alpha）；因子缺失置 NaN 不冒充；
- `pipeline.py`：训练期冻结的 1%/99% 缩尾 → 逐日截面中位数填充 → 逐日截面标准化。

### 3.3 GBS 特征层（`gbs/`）

- `encoder.py`：分位数编码 + 分箱 → 空间×时间二级模式地址（A/B 双区）；fit/freeze 状态机，测试期禁止重新选择映射；
- `backends/`：simulator（高斯 copula 近似）/ cached（样本库命中复用）/ permuted（置换对照）/ hardware（真机接口，P3 用）四后端可切换；
- `sample_store.py`：样本位压缩 npz + 元数据 json；batch_id 由配置确定性派生，命中不重采、结构不一致报错；
- `basis.py`：高阶基两步筛选（论文 arXiv:2506.19707 流程参数化：n1/n2/N + 防组合爆炸 + 可选跨批次稳定性筛选）；
- `feature_service.py`：边际点击率 / 二阶归一化关联 / 高阶基频率（软激活 = 基频率 × 地址重合比例）；预计算缓存 + 按需统计双通道；统计词表 fit 时冻结。

### 3.4 读出模型层（`models/`）

- `readout.py`：Ridge（网格 α∈{0.1,1,10}）与 HistGradientBoosting（刻意不依赖 lightgbm）；
- `selection.py`：特征筛选（IC 均值/IC 稳定性/相关性剪枝/族配额）+ 验证期超参搜索（train 拟合、valid 以逐日 rank IC 均值评分）→ train+valid 合并窗重训后进测试；
- `blending.py`：ρ 收缩网格 0~1（11 点，验证期 IC 最大化；刻意用 train-only 模型估 ρ 防重训乐观偏差）；不确定性三口径（残差 std / 分块 bootstrap / 分位数回归），默认残差法。

### 3.5 组合优化层（`portfolio/`）

- `optimizer.py`：cvxpy 稳健均值—方差，目标 max αᵀw − λwᵀΣw − τ‖Δw‖₁ − γ‖w‖²；约束含个股权重上限（默认 10%）、现金区间（0–5%）、无卖空、黑名单、可选换手/暴露/流动性约束；求解器回退链 CLARABEL→SCS→OSQP；不可解回退上期权重；
- **PSD 修复**（P2 真实规模逼出的 bug 修复）：自有稠密校验 + 负特征值截断后以 `psd_wrap` 提交，跳过 cvxpy 在 800 资产上不收敛的 ARPACK 认证；
- `risk.py`：Ledoit–Wolf（默认）/ 样本协方差 / Barra 式因子风险模型（EWMA 半衰期 60 日，输出前对称化→PSD 投影→尺度校准）；
- `costs.py`：占位成本（佣金/印花税卖出单边/滑点/冲击），真实值待中信交付覆盖。

### 3.6 回测与实验编排层（`backtest/` + `experiments/`）

- `rolling.py`：定长滚动窗（csv 实验 2y/6m/1m，purge 5d + embargo 2d），另有跨界标签硬剔除（训练标签前视窗不得伸入验证期，验证标签不得伸入测试期）；
- `engine.py`：每月首个交易日收盘价调仓；停牌股冻结持仓、预算等比缩放；现金按 rf 计息；单边换手 0.5·Σ|Δw|，成本直接扣净值；
- `runner.py`：每折流程 = 因子模型 fit → 标签 → 预处理 → 编码器 fit/freeze → 特征服务 fit/freeze → 特征筛选 → 超参搜索 → 重训 → ρ 估计 → 优化 → 回测；GBS 样本跨折共用；
- `diagnostics.py`：诊断二/三/四已实装（置换对照、匹配随机特征含分块 bootstrap CI 三分支判定、映射与批次稳定性）；诊断一（真机 vs 仿真）留 P3；
- `report.py`：分块 bootstrap CI、White Reality Check、Deflated Sharpe、BH 校正全部就绪；
- 可复现性：全随机源显式 seed=42；ExperimentResult 记录 git_hash、seed、数据指纹；样本库即缓存（`test_q2_reproducible` 验证两次运行指标完全一致）。

### 4.1 P1 结果（测试窗 2025-08-01 ~ 2025-12-31，103 交易日，占位成本）

| 指标 | C1 | C2 | C3 | C4 | C5 |
|---|---|---|---|---|---|
| rank IC | — | −0.035 | −0.008 | −0.023 | −0.038 |
| ICIR | — | −0.47 | −0.10 | −0.32 | −0.71 |
| Sharpe | 1.26 | 2.68 | 1.49 | −0.02 | 2.55 |
| 年化收益 | 71.5% | 82.5% | 40.1% | −3.2% | 73.9% |

### 4.2 P2 结果（仿真口径，方法学验证，非业务结论）

| 实验 | rank IC | ICIR | Sharpe | 年化收益 |
|---|---|---|---|---|
| Q1（+边际） | −0.042 | −0.57 | 1.08 | 24.8% |
| Q2（+二阶） | −0.035 | −0.44 | 0.71 | 14.8% |
| Q3（+高阶） | −0.029 | −0.39 | 0.71 | 14.9% |
| Q4（全特征+GBM） | −0.022 | −0.33 | 1.29 | 30.9% |

- 全部监督配置 rank IC 为负，Q 系相对 C2 无增量（5 折不具统计推断力）；
- 诊断二（置换）：联合类特征 IC 差 −0.0007，联合结构贡献未获支持；
- 诊断三（匹配随机特征）：GBS −0.0200 vs 匹配随机 +0.0069，CI 整体为负——**仿真 GBS 的增量可由低阶统计 + 随机升维解释**；
- 诊断四：批次边际离散度 0.0479（达标 ✓）；跨映射特征相关仅 0.050（映射选择影响大，验证期选择机制必要性确认）。

### 4.3 为什么仿真无增量是预期内的

仿真器是高斯 copula 近似：只复现边际与两两相关，高阶结构由二阶按固定套路推出，不含独立信息。诊断三证明：仿真 GBS 特征里有的，经典随机特征全有；经典随机特征没有的（独特高阶结构），仿真也没有。该阴性结果**不能外推真机**（真机分布由干涉仪物理决定，含经典难模拟的真实高阶关联），它的价值在于验证诊断体系能正确识别"无独特结构贡献"——标尺已校准，P3 真机是决定性检验。

### 4.4 过程中发现并修复的规模性问题

1. 800 资产协方差矩阵在 cvxpy ARPACK PSD 认证上数值不收敛 → 自有修复 + `psd_wrap`；
2. 诊断三 verdict 在 CI 整体为负时误报 → 新增显著为负分支。

| 5 | P3 链路预置 | `backends/hardware.py`、`diagnostics.py` 诊断一 | 真机样本入库元数据 schema、批次 QC、真机 vs 仿真分布对照，先空跑 |
| 6 | C0 复现管线骨架 | `experiments/` | baseline 数据一到即可跑 |
| 7 | （可选）扩展特征集 extended | `factors/finance.py` | 已实现，待协议允许时启用 |

### 6.3 关键风险（方案书 §8.3 口径）

- 真机机时不确定 → 仿真链路已完成全部方法学验证，采样计划留批次冗余；
- 仿真与真机分布差距 → 最终结论仅以真机样本为准；
- 过拟合与多重比较 → 协议冻结 + §7.4 统计控制已实装，负结果如实报告；
- 单一 6 个月测试窗 + 占位成本 + 快照成分 → 现有全部数字仅作基线参考，数据补齐后全部重跑。
