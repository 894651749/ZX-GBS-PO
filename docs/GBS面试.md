## 第一部分：30 秒介绍

> 这是一个探索"量子采样特征能否增强量化投资"的项目。我把金融特征编码到高斯玻色采样（GBS）装置的模式地址上，从采样数据中提取边际、二阶、高阶联合统计量作为新特征，和经典金融特征拼接后训练 Ridge/GBM 预测中性化收益，再经 Ledoit-Wolf 收缩协方差 + cvxpy 凸优化生成带约束的组合权重。整条管线用 purge+embargo 滚动样本外协议评估，配了十组对照实验和置换/随机特征/bootstrap 三层归因检验。仿真口径下 GBS 特征没有显示出增量——但这是对照体系设计要识别的情形，阴性结果本身验证了评估框架的有效性。

## 第二部分：方案运行框架（全流程）

整个方案分七个环节，数据从原始交付文件流入，最终产出可检验的实验结论。

**一、数据接入与校验**
接入中信交付的行情、静态资料、指数数据（800 股 × 727 交易日），经 ETL 转换为标准数据文件，用 pydantic 做行级 schema 校验。关键口径处理：日收益必须用"复权收盘 ÷ 复权前收盘"（除权日前收按新因子调整，收盘环比会引入分红跳变）。产出：干净、口径统一的建模数据。

**二、特征工程（双通道）**
- 经典通道：计算 11~19 个金融特征（动量、反转、波动率、偏度、峰度、流动性），全部只用当日及之前数据，训练窗内缩尾、逐日截面 z-score；
- GBS 通道：金融特征经**分位数编码**映射到采样装置的模式地址，从采样样本中提取三层统计量——边际点击概率、二阶联合点击率、筛选后的高阶模式基频率。

**三、特征融合与标签构造**
两层融合：特征层拼接 ψ = [x ; φ_GBS]；预测层 ρ 混合 α_final = (1−ρ)·α_base + ρ·α_GBS（ρ 验证期选定，兼作归因旋钮和降级开关）。标签为**中性化收益**：未来 21 日收益减去市场+行业因子贡献（联合 OLS 估计暴露），让模型只学纯 alpha。

**四、模型训练**
读出模型用 Ridge（闭式解、归因清晰，主配置）和 GBM（检验非线性融合增量）；可选不确定性折扣 α̃ = α − κ·δ̂（预测没把握的股票预期收益往零收缩）。

**五、风险估计与组合优化**
风险矩阵用 Ledoit-Wolf 收缩协方差（压制小样本估计误差），进优化器前做半正定修复。cvxpy 求解：max 收益 − 风险惩罚 − 换手惩罚 − 权重正则，约束含无卖空、个股上限 10%、现金 [0,5%] 及行业暴露区间；求解器 CLARABEL→SCS→OSQP 回退链。

**六、回测执行**
逐日仿真：权重随收益漂移 → 调仓日优化出目标权重 → 扣除佣金/印花税/滑点成本 → 停牌股票权重冻结、剩余预算归一化。产出净值、换手、成本台账。

**七、滚动评估与增益归因**
train 2年/valid 6月/test 1月逐月滚动，purge 剔除标签跨界样本 + embargo 2 天隔离带防泄漏。指标分预测层（rank IC）与组合层（Sharpe、回撤、换手）两层报告；增益归因三层证据：十组对照矩阵 → 置换/匹配随机特征对照 → 分块 bootstrap 置信区间 + 多重比较校正（DSR、White 检验、BH）。

## 三、按简历条目组织的预测问题与参考答案

### Bullet 1：特征与建模

> 简历原文：*独立搭建从数据接入到回测评估的端到端 ML 管线；设计分位数编码与稀疏基高阶特征提取方案，从大规模采样数据中提取多维统计特征，基于 Ridge/GBM 集成模型完成预测，并结合收缩估计与 cvxpy 凸优化实现带约束的下游决策配置。*

---

**Q1.1 分位数编码具体怎么做的？为什么不用标准化或直接喂原始值？**

答：在训练窗内对每个金融特征拟合经验分布函数 F̂，把特征值 x 映射为分位数 u = F̂(x) ∈ [0,1]，再把 u 分箱（demo 配置 A/B 两区各 16 箱）得到分箱编号 q。q 决定 GBS 装置的"时间模式"地址，特征序号 j 决定"空间模式"地址——这样每个（股票, 特征, 取值水平）就对应采样空间里的一个具体模式。

为什么不用 z-score 标准化：分位数变换**保单调、抗离群值**（金融收益有肥尾，+418% 的极端收益在 z-score 下会污染整个截面），且分箱边界只用训练期分位点估计、测试期冻结，越界值截断到端点箱——样本外编码始终合法，天然防泄漏。

实现要点（被深问时抛出）：编码器是 fit → freeze → transform 状态机——fit 在训练窗估计分位边界，freeze 返回不可变副本，只有冻结副本允许 transform。NaN 用训练期中位数填充。

**Q1.2 "稀疏基高阶特征提取"是什么？为什么不枚举所有高阶组合？**

答：两步法筛选（与参考论文一致）：
1. 从采样批次随机抽 n1 个 shots 作为参考集；
2. 每个 shot 保留按边际频率排序的 top-n2 个点击模式；
3. 统计这些模式的 d 阶组合在各参考样本中的共现频次；
4. 按跨样本合计频次降序保留 top-N_B 个候选基；
5. 叠加跨批次稳定性筛选（频率的相对标准差 ≤ 0.5），剔除不稳定基后冻结。

为什么不枚举：M 个模式的 3 阶组合数是 C(M,3)，真机 M=8176 时约 9×10¹⁰，完全不可行。两步法用"高频样本里的高频模式"把搜索空间压到 N_B=3000 量级。实现上还有 `max_combos_per_shot` 防止单个高密度 shot 的组合爆炸。

"稀疏"体现在：高阶基特征用 CSR 稀疏矩阵存储，且采用软激活（特征值 = 基频率 × 重合数/阶数），避免硬激活在小规模寻址下退化为全零。

**Q1.3 从采样数据里提取了哪些统计特征？**

答：三层，对应假设 H1–H3：
- **边际特征**：每个模式的一阶点击概率（F 维）；
- **二阶特征**：模式对的联合点击概率 / 协方差 / 相关系数（F(F−1)/2 维）；
- **高阶特征**：上题筛选出的高阶基组合的联合点击频率（N_B 维）。

**Q1.4 Ridge 和 GBM 怎么"集成"的？**

答：不是 stacking，是 **ρ 收缩混合**：α_final = (1−ρ)·α_base + ρ·α_GBS。其中 α_base 是纯金融特征的 Ridge 预测，α_GBS 是拼接特征模型的预测。ρ 在**验证窗**按逐日 rank IC 最大化做网格搜索（[0,1] 取 11 个点），选定后冻结进测试期。

为什么这样设计：它提供了一条**可控降级路径**——当 GBS 特征在某些市场阶段失稳时，验证规则可以把 ρ 调向 0，系统自动退回经典基线。GBM 用的是 sklearn 的 HistGradientBoostingRegressor（不强制 lightgbm 依赖）。

**Q1.5 预测目标是什么？为什么要中性化？**

答：标签是未来 21 日前向收益减去同期市场 + 中信一级行业因子的收益贡献（联合因子模型 OLS 估计暴露 β，y = r − β̂ᵀf）。

为什么中性化：组合在行业和风格约束下做相对选股，预测"扣掉市场与行业 beta 后的纯 alpha"才能让预测目标与组合目标一致；联合模型（市场和行业进同一回归）避免把行业收益里已含的市场成分重复扣除。

**Q1.6 收缩估计用在哪里？为什么需要？**

答：Ledoit-Wolf 收缩协方差，作为 cvxpy 均值-方差优化器里的风险矩阵 Σ̂。

为什么需要：100 个资产只用约一年日收益估计协方差时，样本协方差接近病态（特征值谱过散），优化器会**放大估计误差**——表现为权重集中、换手飙升、样本内外表现分化。这正是客户原模型"大资产池反而更差"的核心诊断。LW 收缩把样本协方差向结构化目标（单位阵的倍数）压缩，数学上有良好的渐近性质。另有 Barra 式因子风险模型（Σ = BΣf Bᵀ + D）作为可选口径。

**Q1.7 组合优化的完整形式？求解器怎么用？**

答：目标函数 max αᵀw − κ·wᵀΣw − τ·‖w−w_prev‖₁ − γ·‖w‖₂²，四项分别是预期收益、风险惩罚（κ 风险厌恶）、换手惩罚（τ，L1 范数鼓励少交易）、权重正则（γ，防集中）。

约束：权重和 = 1、无卖空、个股上限 10%、现金 ∈ [0, 5%]、可选最大换手、行业/风格暴露区间、黑名单、流动性约束。

求解器：CLARABEL → SCS → OSQP 回退链；求解失败不抛异常，回退到上一期权重并记录诊断。

**Q1.8（高频难题）讲一个真实踩过的坑。**

答：800 资产的协方差矩阵提交给 cvxpy 时，其内部用 ARPACK 做 PSD（半正定）认证，在这个规模上**数值不收敛**，优化直接失败——小规模 mock 测试永远碰不到这个问题。解法：先用自实现的稠密 PSD 校验 + 最近半正定投影（负特征值截断）修复矩阵，再用 `cp.psd_wrap` 告诉 cvxpy"这个矩阵我已确认 PSD，跳过内部认证"。这个 bug 是真实数据规模逼出来的，也是坚持"mock 只用于单测、结论必须真实数据重跑"的原因。

### Bullet 2：评估方法论

> 简历原文：*构建 purge + embargo 防数据泄漏的滚动样本外评估管线，设计十组对照与逐层消融实验矩阵，通过置换对照、随机特征对照与 bootstrap 置信区间建立严格的增益归因方法，保证实验结论的统计可靠性。*

这是简历最强的一条，也会被问得最深。**建议把这一节的所有答案练到脱口而出。**

**Q2.1 purge 和 embargo 分别防什么？能画图说明吗？**

答：两者防的是**时间序列交叉验证里标签和信息的跨界泄漏**，但机制不同：

```
        train        |  valid  |embargo|  test
  ──────────────┬─────────────┬──┬────────────
                ↑purge 区      ↑2 天隔离带
   train 末端样本的标签窗口（前向 21 天）会伸进 valid/test
```

- **purge（剔除）**：标签是未来 21 天收益，训练集末尾样本的标签窗口会伸进验证/测试期——把这些"标签跨界"的训练样本**整条剔除**，purge 长度 ≥ 预测期限 h；
- **embargo（隔离带）**：在 valid 结束和 test 开始之间留一段空档（2 天），防止边界处的自相关信息渗透；
- 实现上还有第三层**标签前视窗硬约束**：代码强制校验 train 标签不伸入 valid、valid/train 不伸入 test，发现即报错。

为什么不只做普通 k-fold：金融时序打乱顺序就引入了未来信息；普通 walk-forward 不处理标签重叠，21 天的前向标签会让 train/test 共享同一段行情。

**Q2.2 十组对照矩阵的设计逻辑？（本项目方法论的核心，必考）**

答：设计目标是**归因递进**——把"GBS 特征带来的提升"从所有混淆因素里一层层剥离出来：

| 编号 | 配置 | 排除的混淆因素 |
|---|---|---|
| C0 | 客户原均值-方差复现 | —（锚点） |
| C1 | 修正口径 + LW 收缩的经典基线 | 口径错误 |
| C2 | 金融特征 + Ridge | —（ML 线性基线） |
| C3 | 金融特征 + GBM | —（ML 非线性基线） |
| C4 | + 分位数 one-hot + 显式交互 | "离散编码本身"的贡献 |
| C5 | + 等维 RFF/Nyström 随机特征 | "单纯把特征变多"的贡献 |
| Q1 | + GBS 边际特征 | 对应假设 H1 |
| Q2 | Q1 + 二阶联合特征 | 对应假设 H2 |
| Q3 | Q2 + 高阶基 | 对应假设 H3 |
| Q4 | 全特征 + GBM | 完整配置，对应 H4 |

关键设计细节要能讲出：
- **C4 是 GBS 编码的"同族安慰剂"**：GBS 编码本质是分位数离散化 + 映射，C4 用纯经典方式做同样的事——如果 C4 也有增量，那增益来自编码方式而非采样；
- **C5 的"等维"**：随机特征维数与对应 Q 系 GBS 特征维数严格一致，保证比较在**相同模型容量**下进行——否则"特征多了所以好了"说不清；
- **递进判定规则**：每一层假设（H1→H2→H3→H4）只有通过样本外显著性检验，才扩大下一层复杂度；未通过就停止并如实报告负结果。

**Q2.3 置换对照和随机特征对照分别回答什么问题？**

答：这是两种互补的归因工具：
- **置换对照**（permutation）：把 GBS 特征面板按模式列独立打乱——**保持边际分布、破坏联合结构**。如果二阶/高阶特征的预测力来自联合结构，置换后 IC 应显著下降。回答的问题：*联合结构有没有贡献？*
- **匹配随机特征对照**：用高斯 copula 生成与 GBS 特征**边际分布和二阶协方差都匹配**的随机特征，走完全相同的读出链路。回答的问题：*就算联合结构有贡献，是不是随便什么有相同低阶统计的随机特征都行？*

只有 Q 系显著优于匹配对照，才能把增量归因于 GBS 采样分布的**独特物理结构**，而不是"随便什么非线性升维"。

**Q2.4 为什么用分块 bootstrap 而不是普通 bootstrap？**

答：普通（iid）bootstrap 假设样本独立，但 IC 时间序列和组合日收益有显著自相关——iid 重采样会破坏时间依赖结构，**低估方差、让置信区间过窄**，得出虚假的显著性。分块 bootstrap（moving block，块长 21 天 ≈ 一个调仓周期）按连续时间块重采样，保留块内自相关。消融对比用**同索引配对重采样**：所有配置在同一些重采样块上算指标再求差，消除块间运气差异，增量 CI 才干净。

**Q2.5 多重比较问题怎么处理？**

答：在十组配置、多组参数里"挑出最好的"，本身就是数据挖掘，会高估最优结果。三层防护：
- **Deflated Sharpe Ratio（DSR）**：校正多重试验和非正态性后，评估"最优 Sharpe 仍显著为正"的概率；
- **White Reality Check**：用平稳 bootstrap 检验"最优配置相对基准是否真实占优"；
- **Benjamini-Hochberg（BH）程序**：同一测试期上全部配置构成一个检验族，控制错误发现率（FDR）。
显著性水平、检验族构成、全部判定阈值在**测试前锁定并版本化**——先有规则后看数据，不是看完数据再定规则。

## 五、术语速查（被问到时的一两句话解释）

**GBS（高斯玻色采样）**：一种量子光学采样方案——压缩光态经过线性干涉网络（分束器阵列），由光子探测器读出各模式的光子数（click 模式）。输出样本服从由干涉网络决定的复杂多模式联合分布，其概率与矩阵的 Hafnian/Torontonian 相关，经典计算随规模指数困难。本项目把它的样本当作"由物理结构决定的高维关联特征源"。

**Hafnian / Torontonian**：矩阵函数。Hafnian 对应光子数分辨探测的 GBS 概率，Torontonian 对应阈值探测（click/不 click）的概率。两者都是 #P-hard——这正是 GBS"经典难模拟"的数学根源。被问到知道名字和含义即可，不需要会算。

**压缩光（squeezed light）**：量子光学态，某个正交分量的噪声被压缩到真空涨落以下。GBS 的输入态。知道名字即可。

**rank IC**：截面预测值与未来实际收益的 Spearman 秩相关系数，逐日计算取时间序列。量化领域衡量选股模型预测力的标准指标；ICIR = IC 均值/IC 标准差，衡量稳定性。为什么用 rank 而不用 Pearson：对离群收益鲁棒，只关心排序（选股本质上就是排序问题）。

**中性化（neutralization）**：从收益中扣除市场、行业等系统性因子的贡献，留下纯个股 alpha。本项目用联合 OLS：r = a + βᵀf + ε，标签 y = r − β̂ᵀf。

**Ledoit-Wolf 收缩**：协方差估计量 Σ_lw = (1−δ)·S + δ·μI，把样本协方差 S 向单位阵方向收缩，收缩强度 δ 有解析最优解。效果：压缩特征值谱、改善条件数、降低样本外波动。

**purge / embargo**：见 Q2.1。López de Prado《Advances in Financial Machine Learning》的术语，量化面试常客。

**置换对照（permutation test/control）**：打乱数据的某些结构，保持其余统计性质不变，用作"零假设"基准。本项目逐模式列独立 shuffle：保边际、破联合。

**高斯 copula 匹配对照**：copula 是把多变量联合分布分解为"边际分布 + 依赖结构"的工具。用高斯 copula 生成与 GBS 特征边际和相关结构都匹配的随机特征——如果这种"纯经典仿制品"表现不差，GBS 的独特性就不成立。

**分块 bootstrap（moving block bootstrap）**：时间序列的重采样方法，按连续块而非单个点抽样，保留块内自相关。环形（circular）变体把序列首尾相接。

**Deflated Sharpe Ratio（DSR）**：Bailey & López de Prado 提出：在尝试了 N 个策略变体后，观察到的最高 Sharpe 存在选择偏差，DSR 校正试验次数、收益非正态性（偏度峰度）和序列相关后，给出"真实 Sharpe > 0"的概率。

**White Reality Check**：White (2000) 的检验：用平稳 bootstrap 构造"没有任何策略能战胜基准"的零假设分布，检验最优策略的超额是否显著。

**Benjamini-Hochberg（BH）程序**：控制错误发现率（FDR，即"宣称显著的结果中假阳性的期望比例"）的多重检验方法，比 Bonferroni（控制族错误率）功效更高。

**RFF / Nyström**：两种经典随机特征方法，用随机投影近似核方法（核技巧）的特征映射。本项目用作 C5 对照——代表"任意非线性随机升维"的水平。

**PSD（半正定）与最近 PSD 投影**：协方差矩阵必须半正定才能进凸优化。数值误差会导致小的负特征值，处理方法是特征分解后把负特征值截断为 0 再重构（Higham 的最近相关矩阵思想的简化版）。

**CLARABEL / SCS / OSQP**：cvxpy 支持的开源凸优化求解器。CLARABEL 是内点法（精度高）；SCS 是一阶算子分裂（大规模鲁棒）；OSQP 专攻二次规划。回退链保证求解失败时系统可用。

**Amihud 非流动性**：|日收益|/成交额 的均值，衡量单位成交额推动的价格变化——越小越流动。常见微观结构特征。

**PIT（Point-in-Time）**：数据按"历史时点真实可见"口径组织，不用未来信息回填历史。当前资产池是 2025 年末快照回贴 2023–2025，**非 PIT**，存在幸存者偏差——这是项目明示的限制。

**Herfindahl 指数（HHI）**：Σ wᵢ²，权重集中度，全等权时取 1/n，满仓单票时取 1。

**CVaR（条件在险价值/预期损失）**：损失分布尾部（如最差 5%）的平均损失，比 VaR 更能刻画尾部风险。

## 八、模型框架与脉络速览（30 秒版的展开）

### 8.1 两层融合（核心设计）

**特征层拼接**：ψ = [x ; φ_GBS]——金融特征（11~19 维，训练窗缩尾+截面 z-score）与 GBS 统计特征（边际 F 维 + 二阶 F(F−1)/2 维 + 高阶基 N_B 维）横向拼接，两边均标准化后量纲一致。对应参考论文的 GRVFL 形态。

**预测层混合**：α_final = (1−ρ)·α_base + ρ·α_GBS。α_base 是纯金融特征 Ridge，α_GBS 是拼接特征模型；ρ 在验证期按 rank IC 网格搜索（[0,1] 共 11 点）后冻结。双重作用：① ρ 是 GBS 贡献的显式归因旋钮（ρ=0 即经典基线）；② 工程降级路径——GBS 特征失稳时 ρ→0 自动退回经典模型。

### 8.2 下游链路（融合之后，按数据流向）

1. **标签**：y = 未来 21 日累计收益 − β̂ᵀ·（市场+行业因子收益），β̂ 由训练窗联合 OLS 估计。理由：预测目标与"行业约束下相对选股"的组合目标口径一致，模型只学纯 alpha。
2. **读出模型**：Ridge（闭式解、λ∈{0.1,1,10} 验证期选，归因清晰，Q1–Q3 主配置）+ GBM（HistGradientBoosting，检验非线性融合增量，Q4/C3）。
3. **不确定性折扣（可选）**：α̃ = α − κ·δ̂，δ̂ 由残差/分块 bootstrap/分位数回归估计；默认 κ=0，验证期决定是否启用。
4. **风险估计**：Ledoit-Wolf 收缩协方差 Σ_lw = (1−δ)·Σ_sample + δ·μI，压制小样本下特征值谱过散；进优化器前对称化 + 负特征值截断保证 PSD。
5. **组合优化（cvxpy）**：max α̃ᵀw − κ·wᵀΣw − τ·‖Δw‖₁ − γ·‖w‖₂²（收益/风险/换手/集中度四项权衡）；约束：Σw=1、无卖空、个股 ≤10%、现金 [0,5%]、可选换手/行业暴露/流动性。求解器回退链 CLARABEL→SCS→OSQP，失败回退上期权重。
6. **回测引擎**：逐日推进——权重随收益漂移 → 调仓日优化 → 成本扣减（佣金双边+印花税卖出单边+滑点双边+可选冲击）→ 停牌持仓权重冻结、预算在可交易子组合内归一化。
7. **滚动评估**：train 2y / valid 6m / test 1m 逐月滚动；purge 剔除标签跨界训练样本（≥21 天），embargo 2 天隔离带，代码硬校验标签窗口越界即报错。
8. **归因与检验**：预测层（rank IC/ICIR）与组合层（Sharpe/回撤/换手/HHI）分开报告；增益证据三层——对照矩阵增量 → 置换+匹配随机特征对照 → 分块 bootstrap CI + DSR + White RC + BH 校正。

一句话脉络：**两层融合进模型，中性化标签定目标，收缩协方差稳风险，cvxpy 四项权衡出权重，成本+停牌仿真出净值，purge/embargo 保干净，三层归因下结论。**
