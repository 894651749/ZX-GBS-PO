# 数据完备性与项目可推进程度评估

- **评估日期**：2026-09-28
- **判定标准**：`9.22方案书-GBS量子特征增强的投资组合优化.md`（§9 数据提供清单、§7 实验与验证设计、§8 实施计划）
- **评估对象**：`data/` 目录首批交付（静态数据_1.csv、行情数据_1.csv、指数相关时序数据_1.csv、GBS数据情况汇总.xlsx、资讯(1).7z）
- **约束原则**：后续任务只使用真实交付数据；对真实数据的清洗、单位换算、列名映射与计算派生（日收益、特征、停牌标记、行业映射）属数据处理而非数据生成；mock 合成数据仅可用于单元测试，不得用于任何结论性实验。

> 特殊说明：GBS 侧的**仿真样本**（simulator/cached 后端）是方案书 §1.3/§3.4 明文规定的方法学环节（P2 仿真口径初验），与伪造金融数据无关；最终结论仍以真机（P3）为准。现有 `sample_store/simulation/` 下为两个开发规模样本库（32×16/32×9 模式、2 万 shots，远低于真机目标 8176 模式、10⁶–10⁷ shots）。

## 一、总体结论

**七类首批交付文件：2 类基本齐备、3 类部分可用、2 类完全缺失。综合完备度约五到六成——足以支撑"管线闭环 + 经典对照 + GBS 仿真口径方法学验证"（P0 大部分、P1、P2），不足以支撑任何业务级结论（C0 复现、正式 H1–H4 判定、P3）。**

数据与代码架构的兼容性良好：适配器接口（`src/qgbs/data/adapters/base.py`、`csv_adapter.py`）即按方案书 §9 中信交付口径设计，交付数据语义与接口一一对应，**无需改架构，只需一个 ETL 转换层**。真正的瓶颈不是兼容性，而是三个关键缺失（29/100 池定义、constraints_costs、baseline_results）和一个隐形的时间维度缺口。

## 二、交付数据盘点

### 1. 静态数据_1.csv —— 800 只股票静态档（约 256KB）

- 800 只 A 股 = 沪深300（300）+ 中证500（500），即**中证800 的 2025 年末时点快照**（GBS数据情况汇总.xlsx 确认）；SH 466 / SZ 334；主板 616、创业板 100、科创板 84。
- 字段：代码/交易所/简称/上市日期/板块/公司信息/中信一、二、三级行业/总股本/流通股本/所属指数。
- 覆盖全部 30 个中信一级行业（电子 98、医药 74、非银 59 等）；上市日期 1990–2025-07；**无任何退市股票**。
- 缺：行业历史变更、行业排名、29/100 池归属、现金资产定义。

### 2. 行情数据_1.csv —— 日频行情（约 63MB，575,079 行）

- 800 股 × 727 交易日，**2023-01-03 ~ 2025-12-31（整 3 年）**；与静态档 800 股完全一致；无重复主键、无缺失值。
- 字段：复权前收盘/复权开盘/复权收盘、成交量、成交额、换手率、总市值、流通市值、ST 标记、可否买卖。
- **口径实测（已验证）**：价格为**后复权价**（000001.SZ 收盘约 950 元 vs 实际约 11.5 元）；成交量单位**手**（×100=股）；成交额**元**；市值**万元**（×1e4=元，用 总市值×1e4/总股本≈实际价 验证）；换手率 **%**。
- **无最高价/最低价**、无未复权价、无复权因子列、无涨跌停价。
- 可交易性：停牌 443 行（可否买卖=否 且 量/额/换手=0，携带价格）；ST 仅 3 只股票、324 行；27 只为 2023 年后次新股（最少覆盖 105 天）。
- **除权处理**：772 行（718 股）出现 复权前收盘 ≠ 昨日复权收盘（逐日复权因子口径）——主要集中于 2023 年 8 月中报分红潮（716 行，差异中位数仅 0.0026%），个别大额（最大 38.5%，疑似送转，待与数据商核实）。**日收益必须用 复权收盘/复权前收盘−1，不能用收盘价环比**。
- 极端收益：日收益 max +418%、min −49.97%（新股首日/复牌类，建模前需核实与缩尾）。

### 3. 指数相关时序数据_1.csv —— 指数日行情（约 2.1MB，23,264 行）

- **32 只指数 × 727 天（2023-01-03 ~ 2025-12-31）**，无缺失：沪深300、中证800 + **全部 30 个中信一级行业指数**（CI005001–CI005030），与静态档 30 个中信一级行业一一对应。
- PCTCHANGE 为小数口径日收益，CLOSE 为点位。市场因子 + 行业因子收益齐备，中性化联合因子模型（`src/qgbs/factors/neutralization.py` JointFactorModel）可直接构建。
- 缺：无风险利率、现金管理收益率、风格因子（方案书 §9.2 允许用行情自建，非阻塞）。

### 4. GBS数据情况汇总.xlsx —— 交付方自查清单

基础信息/资产池与行业/股本复权三类均标"已完成"，并自述两个口径问题：**资产池取 25 年末时点快照**；静态档缺"总流通市值口径"指标（行情表内有日频流通市值，可补上）。

### 5. 资讯(1).7z —— 文件名误导，无增量内容

解压后为与上述相同的 3 个 CSV，**不是舆情数据**。方案书 §9.3 的基本面、资金流、分析师预期等补充数据本阶段均未交付（方案定位为第二阶段补充，不阻塞）。

## 四、隐形缺口：时间维度（单独强调）

1. **历史仅整 3 年（727 个交易日），踩方案书"至少 3 年"下限。** 按 §7.2（train 2–3y + valid 3–6m + test 按月滚动），唯一可行的方案书口径切分是 **train 2 年 + valid 6 个月 + test 6 个月 ≈ 6 个测试折**（mom_120 特征热身再在训练窗内消耗约半年）。
2. **测试期约 6 个月 → §7.4 的分块 bootstrap、DSR、White 检验、BH-FDR 统计功效弱**，H1–H4"显著为正"判定大概率得不出强结论。方案 §2.3 有明文预案："历史范围有限，则相应降低结论强度"。
3. **2026 年 1–4 月数据完全缺失**（数据止于 2025-12-31），§1.1 原业务评估窗复盘做不了——与 baseline_results 缺失叠加，**与中信原结果的直接对标目前不可能**。
4. 有利面：2023–2025 内含下跌、2024-09 行情、2025 上行等多个市场阶段，3 年内有一定状态覆盖。

## 五、与代码架构的兼容性

**结论：语义高度对齐，零架构改动，一个 ETL 层（约一两百行）即可接通。** runner 已内置 `data.adapter: csv` 分发（`runner.py:432-441`），消费顺序为 asset_pool → daily_market/trading_status → market_sector_factor → constraints_costs。

ETL 转换清单（全部为真实数据口径处理）：

| 交付数据 | 框架文件 | 转换内容 |
|---|---|---|
| 行情数据 | daily_market.csv | 列名汉转英；**daily_return = 复权收盘/复权前收盘 − 1**（不可用收盘环比：772 个除权日前收用新因子）；成交量×100（手→股）、市值×1e4（万元→元）；return_basis=adjusted；high/low 暂以 open/close 区间占位并标注待补 |
| 行情+静态 | trading_status.csv | is_suspended=（可否买卖=否）；buyable/sellable←可否买卖；is_st←ST 列；list_date←静态档；lot_size=100 |
| 指数数据 | market_sector_factor.csv | 转长表（trade_date, code, kind, value）；000300/000906→kind=index，CI005xxx→industry；value 用小数日收益 |
| 静态数据 | asset_pool.csv | 代码/交易所/行业/上市日期映射；pool_id **如实**定义（中证800 全集，如 `zz800`），**29/100 无法如实定义**；现金资产行待中信口径 |
| —— | 行业名→CI 代码映射 | JointFactorModel 要求行业列值与因子列名一致（`neutralization.py:100-104`）；30 行业与 30 CI 指数名称一一对应，映射确定无歧义 |

两个代码级使用约束（非改动）：

- 因子管线内部用 close 的环比与比值（`finance.py`），故喂给特征管线的 "close" 应是以 daily_return 连乘重构的一致复权价，否则 772 个除权日的动量/波动特征含分红跳变噪声；
- 暴露矩阵目前为静态行业哑变量（`runner.py:496`，注释已标注"真实数据须用 PIT 暴露"）——静态档只有当前行业、无变更历史，属可接受近似，报告中须注明。

## 六、用现有数据可推进的程度

| 阶段 | 能否推进 | 具体边界 |
|---|---|---|
| **P0** 工程闭环与基线复现 | **大部分能** | ✅ 数据接入与验收（本报告即主体）；✅ ETL + csv 适配器端到端跑通；✅ C1 可比经典基线（修正口径 + Ledoit-Wolf 收缩 + 稳健约束）；❌ **C0 真复现做不了**（缺 baseline_results 与 29/100 池），P0 验收项"基线复现满足容差"无法达成 |
| **P1** 经典对照 | **能（结论降格）** | ✅ C2 岭回归、C3 GBM、C4 分位显式交互、C5 随机特征均可在真实数据上运行；✅ 滚动协议、超参网格、检验口径可冻结版本化。⚠️ 测试期仅 ~6 个月、池非 PIT、成本为占位——产出仅作"协议演练 + 管线正确性验证 + 经典上限初步估计"，不作交付结论 |
| **P2** GBS 特征与仿真验证 | **基本能** | ✅ 编码器、特征服务、样本库版本管理已就绪；✅ Q1–Q4 仿真口径、置换对照、匹配随机特征、批次稳定性诊断可与真实金融数据对接运行；✅ H1–H3 仿真口径初验可完成。⚠️ 仿真样本规模需从开发规模（2 万 shots）提升至 10⁶–10⁷ 量级；结论同受测试期限制 |
| **P3** 真机采样与最终评估 | **不能启动** | ❌ 无真机样本（依赖机时申请）；❌ 正式 H1–H4 判定同时被三个关键缺失 + 历史长度阻塞 |

**一句话：现有数据可推进到 P2 收尾——全管线真实数据贯通 + 经典对照跑完 + GBS 特征仿真口径方法学初验完成；P0 的 C0 验收项、P3 全部、以及任何面向业务的正式结论，均被数据与机时双重阻塞。**

## 七、必须向中信补充的清单（按优先级）

1. **29/100 资产池名单 + 构建规则**（行业排名口径与计算时点）+ 现金资产定义——业务对象本体，最高优先级；
2. **constraints_costs**：费率、印花税、滑点/冲击、权重上限、现金比例区间、调仓频率与日期、流动性限制——既是运行必需文件，又是 H4 结论输入；
3. **baseline_results**：原模型池名单、权重、收益矩阵、参数、2026.1–4 绩效明细——C0 复现与业务对标前提；
4. **历史区间扩展至 ≥5 年（含历史指数成分与行业变更）**——解除"PIT 快照"与"测试期 6 个月"两个结论级限制；若只能补一段，优先补 2020–2022 行情 + 成分；
5. **2026 年 1–4 月行情**——恢复原业务评估窗复盘能力（依赖第 3 项同时到位才有意义）。

非必需但建议补充：未复权价 + 复权因子（审计口径）、涨跌停价（精确可执行性）、无风险利率/现金管理收益率序列（Sharpe 与现金计息口径）。
