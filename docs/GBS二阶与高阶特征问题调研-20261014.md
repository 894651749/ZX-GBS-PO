# GBS 二阶/高阶特征无效问题调研

> 日期：2026-10-14
> 问题：为什么在 26 维经典特征 + GBS 模式寻址的管线中，真机 GBS 的**边际特征有效**（Q1−C2 = +0.0332，CI 不含零），而**二阶与局部高阶特征全部无效**（E5 筛选 2409 候选跨折全灭，直方图贴合纯噪声零假设）？
> 方法：① 彻查本项目代码中 GBS 特征的完整生成链路；② 通读九章论文《Enhanced Image Recognition Using Gaussian Boson Sampling》（arXiv:2506.19707，仓库内有 PDF）并逐项对照。

---

## 1. 一个关键事实：九章论文的范式与我们完全相同

先纠正一个容易产生的直觉：九章论文**也不是**"图像逐张进量子设备"。其流程是：

1. 先用九章 4.0 一次性采好 **900 万个固定样本**（8176 模 = 511 时间模 × 16 空间模，1024 个单模压缩态输入，平均 ~2200 光子点击，样本效率 η≈0.50）；
2. 设备参数全程固定，之后所有"编码"都是**经典的模式寻址**——"第 i 个特征对应第 i 个空间模，特征值决定选哪个时间模"（p.2）；
3. 论文明确说这是为了**避免逐样本重编程**（"significantly reduces programmability requirements"，p.5）。

**这与我们的管线（固定真机采样流 + 分位数寻址查表）在范式上没有区别。** 因此"他们有效、我们无效"的答案不在范式，而在 §3 的四个具体差异。

## 2. 我们的 GBS 特征生成链路（代码事实）

数据流：

```
日频行情 → 26维经典特征 → 截面z-score → QuantileEncoder（训练窗分位边界，511 bin）
  → 寻址：mode_index = bin×16 + (特征号 mod 16)   （encoder.py:312-318）
  → GBSFeatureService（词表 = hw-5M-b0 前 200k shots 的经验统计）→ gbs_* 特征
```

三类特征的构造（`src/qgbs/gbs/statistics.py` + `feature_service.py`）：

| 特征 | 构造 | 本质 |
|---|---|---|
| 边际（26 维） | `p̂[mode(f_j, bin_j)]`，模式经验 click 频率查表 | 一元固定查表 → 已证与 C4 分位数升维打平 |
| 二阶（325 对） | `ρ̂[mode_i, mode_j]`，200k shots 估计的 8176×8176 相关矩阵查表 | 固定相关曲面上的二元采样点 |
| 高阶（2084 基） | 全局高频三元组基频率 × 软激活（重合数/3 加权） | 输入无关基 + 粗化稀释 |

两个结构性事实：

- **确定性**：词表冻结后，一切 GBS 特征都是输入分位数 bin 向量的**确定性函数**，shot noise 只在词表构建一处进入（E4.4 已定性："GBS 编码是一种有效的确定性非线性升维"）。
- **寻址碰撞**：26 维特征 mod 16 个空间模 → 特征 f 与 f+16 共享空间模（10 对），同 bin 时寻址到**同一个模式**；A/B 分区机制在当前"满覆盖"参数化下结构性无效（E3.1 已证 b=255/256 逐比特等价）。

## 3. 四层归因

### 3.1 任务信号天花板（最根本，改不了）

- 论文侧：GELM（纯 GBS 特征，不用原像素）MNIST 准确率 **95.27%**，比 perceptron 高 9.26 个百分点——标签结构几乎完整保留在 GBS 映射里，有大量结构可展开。
- 我们侧：26 维全部家当 GBM 只到 **IC +0.0352**；E1.1 证明中信全部数据 ridge 口径只值 +0.0175。收益预测的可挖掘信号近零，且 GBM 已基本挖尽。
- **非线性映射不能凭空造信号**：没有真实存在的二阶/高阶交互，展开得再好也挖不到东西。

### 3.2 特征构造保真度：我们把"联合指纹"退化成了"低阶标量查表"

论文的特征是：**被寻址 16 个模式上 2^16 种联合点击 pattern 中 top-N（默认 N=3000）的频率直方图**，每组 3000 维，M=32 时共 **6000 维**。这是寻址子集上**直到 16 阶的完整联合分布指纹**——输入变一点，寻址模式集就变，整个 6000 维指纹随之改变，表达力极强。

我们把同一个分布压缩成了 1/2/3 阶标量：边际是 26 个一元查表；二阶是 325 个二元查表，其值是否有用取决于设备相关曲面**恰好**与金融交互效应对齐——没有任何机制保证这种对齐，本质上是一个随机二元函数；高阶是 2084 个与输入无关的三元组基再经软激活稀释。

### 3.3 基选择与寻址的两个独有缺陷（可修）

- **基选择与输入脱节**：论文用 **1000 张训练图的寻址结果**统计哪些 pattern 高频（输入条件化）；我们的 `basis.py` 选的是**设备分布中全局高频的三元组**，与金融输入实际寻址到哪些区域完全无关。选出的基在真实金融行上很少激活，软激活进一步摊薄。
- **碰撞未处理**：论文用 **A/B 时间分区**消组间碰撞（奇数组在 A 区计数、偶数组在 B 区）；我们禁用了分区，10 对特征结构性碰撞。

### 3.4 估计噪声（次要但真实）

- 论文用 **5M shots**（其自测的饱和点：超过 5M 精度不再变化）；我们冻结 **200k**。
- 边际层面 E3.2 已证 200k 足够（加到 1M，rank IC 变化 ≤7e-4）；但二阶 `ρ̂` 在 200k 下估计噪声 σ≈0.0022，**与设备真实模式间相关性同量级**；三阶联合频率计数稀疏、相对误差最大。
- E5 闸门 1 的 4×50k 子批次一致性检验（≥0.8）本质是对该噪声的显式测量：2409 候选全灭；过 2 折者实测 9 个，**低于纯噪声零假设期望（≈17 个）**——当前构造下二阶/高阶个体差异淹没在"采样噪声 × 无对齐"双重噪声中。

## 4. 我们与九章论文的对照总表

| 维度 | 九章论文 | 本项目 | 影响 |
|---|---|---|---|
| 范式 | 固定采样流 + 经典寻址 | 同左 | 无差异 |
| 任务信号 | 图像标签结构强（GELM-only 95.27%） | 收益预测天花板 IC≈0.035 | **决定性差距** |
| 特征形式 | 寻址 16 模上 top-3000 联合 pattern 频率（6000 维，至 16 阶） | 1/2/3 阶标量查表（26/325/2084 维） | 表达力天壤之别 |
| 基选择 | 以 1000 张训练图寻址为条件 | 设备全局高频，输入盲 | 我们的基与任务不对齐 |
| 组间碰撞 | A/B 分区消除 | 分区被禁用，10 对碰撞 | 可修 |
| Shots | 5M（饱和点） | 200k（边际够用，二阶/高阶欠估计） | 可修 |
| 读出层 | 伪逆线性读出（ELM/RVFL） | ridge / GBM | 非核心差异 |
| 量子性对照 | 压缩态比同光子数相干态高 ~6pp | Q1−匹配RF 通过、Q1−C4 打平 | 我们的量子性在任务层不可见 |

## 5. 后续建议（按优先级）

1. **论文级忠实复现（决定性实验，最推荐）**：特征构造改为论文原版——26 维分两组（特征 0–15 进 A 区、16–25 进 B 区，天然消碰撞），每行寻址 16+10 个模式，在 **5M shots** 上统计寻址子集的联合点击 pattern 直方图，用训练行选 top-N 基，归一化+sigmoid 后拼接 26 维经典。
   - 这是"我们的无效是构造问题还是任务问题"的**终审判决**：若论文原版构造也无效 → 任务天花板实锤，GBS 线按"边际兜底"收口；若有效 → 此前的负结论全部需要改写。
2. **输入条件化基选择**（保留现有低阶框架的最小修补）：基选择改为以训练行寻址集合为条件计数，而非设备全局高频。
3. **5M shots 词表稳健性**（便宜的排除项）：对二阶/高阶词表做一次全量 5M 重建 + Q2/Q3 指标复核，彻底关掉"采样不足"嫌疑。
4. **若 1–3 全阴性**：家族级判决成立，最终 Q4 = 26 经典 + 边际；随后转向方案书 §6.1 风险先验方向（波动率/相似性具有真实的二阶结构，比收益预测更可能与 GBS 相关矩阵对齐）。
