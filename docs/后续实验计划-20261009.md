## 0. 前提与现状

**真机数据前提**：真机样本固定为已入库的 `hw-5M-b0` 单批次（5×10⁶ shots，8176 模式，位压缩，`sample_store/hardware/hw-5M-b0/`）。该批次经真机黑盒获得，装置侧标定、多批次采样、η 测定等环节不在本计划范围内；全部优化只能在离线侧完成。单批次带来的两个方法学缺口以诚实标注方式处理：跨批次稳定性用**批内子批次**替代（仅反映采样噪声，不反映装置漂移）；A/B 分区边界 b 用该批次自身 click 剖面**离线标定**（不再需要装置配合）。

**首轮真机结果（2026-10-09 完成）**：Q1H–Q4H 真机口径链路已跑通（200k shots 子采样，全部测试 258 项通过），但相对经典基线**未观测到提升**，按方案书 §7.5 规则 H1–H4 均不成立。根因排序（证据见当日分析）：

1. 基金融特征在当前测试窗口本身无信号（C2–C5 全部 rank IC 为负，-0.008 ~ -0.038）；
2. 统计功效不足：当前协议仅 5 个测试月，IC 组间差异（~0.01）远小于时序噪声；
3. GBS 侧配置未优化：b=256 为占位值、shots 只用 4%、Q3 为缩尺参数（N=50 vs 论文 3000）、单组模式映射。

**已核实的可行性事实**（决定本计划哪些事"立即可做"）：

**总体策略**：Phase 1 的目的不是"先证明经典有信号"，而是**把对照实验的灵敏度修好**（折数 ≥ 15、推断层可用）并建立最强经典基线——当前 5 折协议下 Q vs C 的增量差异远小于置信区间宽度，"没测到增量"与"没有增量"无法区分。仪器修复后，GBS 阶梯在新基座上重跑，**经典基线本身是否为正不构成 GBS 实验的门槛**（方案书 §7.5 的判定本来就是 Q vs C 的增量比较）：若经典无信号而 GBS 增强后为正，是比预期更强的发现。诊断与统计推断（Phase 4）贯穿全程。各 Phase 设进入条件，避免在噪声上堆复杂度。

## Phase 1：经典基线强化（最高优先级）

**目标**：建立最强经典基线，并把对照实验的灵敏度修到足以检出 GBS 增量（折数 ≥ 15、§7.4 推断层可用）。GBS 特征是同一输入的确定性重编码、不引入外生信息——这决定了 GBS 侧调优（Phase 3）应与基线强化共享同一输入基座，但**不构成**"经典先为正、GBS 才配测"的门槛。

### E1.1 扩展特征集对照

- 内容：C2/C3 × {`finance_base`（11 特征）, `finance_extended`}，共 4 个实验配置（复制现有 csv 配置改 `features` 字段，feature_set 经 features 配置传入）。
- 工作量：0.5 天（纯配置 + 跑批，单次分钟级）。
- 判定：extended 相对 base 的 rank IC 增量的块 bootstrap 95% CI 下界 > 0，或 ICIR 明显改善；两者皆无 → 记录负结果，特征扩展就此止步。

### E1.2 滚动协议重划（统计功效优先）

- 内容：在 3 年数据内对照 3 种划分——现状 `2y/6m/1m`（5 折）、`1y/3m/1m`（约 20 折，首个测试月约 2024-04）、折中 `18m/4m/1m`（约 14 折）；用 E1.1 的最优特征集，仅跑 C2/C3。
- 工作量：1 天。
- 判定：首选"折数 ≥ 15 且 IC 均值相对现状不显著恶化"的划分；确定后**冻结滚动协议**（方案书 §7.2），后续全部实验共用。
- 注意：缩短训练窗会降低每折估计质量，这是用折数换功效的显式权衡，须在报告中声明。

### E1.3 业务资产池口径（29/100 池）

- 内容：按方案书业务场景构建 pool29（各行业第 1 名 + 现金）与 pool100（各行业前 4 名 + 现金）：以 `citics_industry_l1` 分组、按调仓时点 `float_mv` 排名生成 PIT 成分表；排名规则与中信确认前，在报告中标注为口径假设。用最优经典配置跑 zz800 / pool100 / pool29 三口径对照。
- 工作量：1–2 天（含池构建脚本与回测口径核对）。
- 判定：池规模对 IC 稳定性与组合指标的影响量化记录；业务交付口径以中信确认的规则为准。
- 依赖：E1.2 完成（协议冻结后跑）。

### E1.4 数据外求（唯一不能离线完成的项）

- 向中信提交补充申请：2020–2022 年历史行情延展（方案书 §9 建议 3–8 年）、真实约束成本参数（现用占位值）、`baseline_results` 原模型交付物。
- 工作量：0.5 天（撰写申请，口径对照方案书 §9.4）。
- 该项不阻塞本计划其余实验；到位后按冻结协议重跑正式结论。

**Phase 1 退出条件**：滚动协议冻结且折数 ≥ 15、最优经典配置确定、§7.4 推断层可用 → 进入 Phase 2/3。**经典基线是否为正不是门槛**：即使最优经典配置 IC 仍接近 0，也照常进入 Phase 3——此时若 GBS 阶梯出现正增量（经典无信号而增强后有信号），是比预期更强的发现；若全部配置仍无增量，负结论也因功效充足而具备统计效力。

## Phase 2：读出模型升级

**前提**：Phase 1 的最优输入（特征集 × 协议 × 池口径）。所有选择只走验证期。

### E2.1 GBM 超参网格

- 内容：`max_depth` × `learning_rate` × `max_iter` × 子采样的小规模网格（≤ 24 组），valid 窗选优；基线为首轮 Q4H 的默认参数（100/3/0.1）。
- 工作量：1 天（含机时）。
- 判定：相对 C3 默认参数的 valid IC 增量为正且测试期不退化。

### E2.2 lightgbm 可选依赖评估

- 内容：`pyproject.toml` 已预留 `gbm` extra；安装后对照 HistGB 后端同网格表现。
- 工作量：0.5 天。
- 判定：仅在显著优于 HistGB 时引入，避免无谓依赖扩张。

### E2.3 线性族与不确定性折扣

- 内容：ridge alpha 网格扩展（现 {0.1,1,10} 扩至 7–9 点）；启用不确定性折扣 ν（`blending.uncertainty.method: block_bootstrap`，ν ∈ {0, 0.5, 1.0}）。
- 工作量：1 天。
- 判定：ν 默认从 0 起步（方案书 §5.4），仅在 valid 上稳定获益时启用。

### E2.4 ρ 混合稳健化

- 背景：首轮真机实验中 ρ 在 4/5 折被选为 1（纯 GBS），而这 4 折测试 IC 全负——验证期选择本身在噪声里。
- 内容：ρ 选择加块 bootstrap 约束（如选 CI 下界最优而非点估计最优），或对 ρ 加收缩先验（向 0.5 收缩）。
- 工作量：1 天。
- 判定：Q4 类配置在冻结协议下测试期 IC 方差下降且均值不退化。

## Phase 3：GBS 侧优化（真机数据固定下的可做项）

**前提**：Phase 1 完成（仪器修复、基线确定），不要求经典基线为正。判定规则沿用方案书 §7.5 的 Q vs C 增量比较，对照组更新为 Phase 1/2 后的 C2/C3/C5。

### E3.1 b 边界离线标定

- 内容：用 `hw-5M-b0` 自身 click 剖面（前 511 时间模式剖面已在入库验证时可算）重新测定 A/B 分区边界，替代占位值 256；对照 b∈{标定值, 256} 两版 Q1H。
- 工作量：0.5 天。
- 判定：若两版 IC 差异在噪声内，冻结为标定值并在报告中记录。

### E3.2 shots 爬坡与全量重跑

- 内容：shots ∈ {200k, 500k, 1M, 2M, 5M}，画"样本量—词表稳定性—rank IC"曲线（方案书 §4.4 判据）；确定平台区后，用全量 5M 重跑最优 GBS 配置。
- 工作量：1 天（机时为主；5M 下 Q2 词表约 9 分钟且跨折缓存，build_features 与 shots 无关）。
- 判定：IC 进入平台区（继续加样本的增量低于块 bootstrap 噪声底）→ 冻结 shots 规模。

### E3.3 V 组模式映射选择/集成

- 内容：P2 遗留项；恒等映射 + 确定性置换变体（V≈4–8），valid 期选择单映射或等权集成。
- 工作量：1 天。
- 判定：映射间 IC 离散度（P2 仿真口径为 0.050）与集成收益量化记录。

### E3.4 编码超参网格

- 内容：`n_bins_a/n_bins_b`（如 {64,128,256} 组合，受地址预算约束）与 activation scale 的小规模网格，valid 选择。
- 工作量：1 天。
- 判定：网格内最大 IC 差异若 < 噪声底，冻结为缺省值，不再调。

### E3.5 批内子批次稳定性筛选

- 内容：将 5M 切为 4–8 个子批，按方案书 §4.2 第 5 步做高阶基稳定性筛选；报告中明确标注此为"批内采样噪声稳定性"，**不构成装置漂移证据**（单批次的固有局限）。
- 工作量：0.5 天。

### E3.6 Q3 论文口径参数（有条件）

- 前置工程：`higher_order_stats` 位域化（packbits 域 `np.bitwise_count` 组合判定），1–2 天。
- 内容：n1=1000 / n2=2000 / N=3000 对照缩尺参数。
- 判定：仅当新基座上 Q1H–Q4H 出现任何 IC 改善迹象、或诊断一（E4.1）显示真机与仿真分布存在显著差异时执行；否则挂起（无任何迹象时投入位域化工程的期望收益过低）。

## Phase 4：诊断与统计推断（贯穿全程）

### E4.1 诊断一：真机 vs 仿真分布对照

- 内容：实现 `hardware_vs_simulation`（`diagnostics.py:31-41`）：边际 L1/L∞、二阶 Frobenius、子系统模式分布；仿真器配成 511×16 对齐模式数。
- 工作量：0.5–1 天（分块二阶件已就绪可直接复用）。
- 价值：把"真机联合结构对本任务无增量"从观察升级为分布级证据；是负结果报告的关键支撑。

### E4.2 诊断三真机版：匹配低阶统计的经典对照

- 内容：P2 仿真口径下 GBS 读出 IC 已低于匹配随机特征（-0.0200 vs +0.0069）；真机口径复跑该对照，完成物理归因闭环（§7.5 物理来源归因条款）。
- 工作量：0.5 天。

### E4.3 §7.4 推断层全面启用

- 前提：E1.2 把折数做够（≥15）。
- 内容：全部正式结论附带块 bootstrap CI；最优组合补 Deflated SR 与 White RC；同一测试期全部配置纳入同一 Benjamini–Hochberg 检验族；显著性水平与检验族构成测试前冻结并版本化。
- 工作量：1–2 天（组件已有，主要是接入实验输出与冻结文档）。

## Phase 5：综合、报告与转向分支

- **综合实验**：最优特征集 × 最优读出 × 最优 GBS 口径 × 业务池（29/100），冻结协议下出正式结果。
- **真机实验报告**：按方案书 §8.2 口径撰写，含 H1–H4 最终判定、诊断一/三证据、负结果如实陈述。

## 下一步执行规划与预期效果分析（2026-10-09）

### 执行顺序（含理由）

```
G0 真机复测 → Phase 2 读出升级 → Phase 3 GBS 调优 → Phase 4 诊断收口 → Phase 5 综合报告
（E1.4 数据外求随时并行发出，不占用实验资源）
```

- **G0 插队**：Q1H–Q4H 在 P1 + extended 基座上复测。首轮真机 H1–H4 的"不成立"是在 5 折仪器 + base 特征上测的，而 E1.2 已证明该仪器连 +0.028 的真实效应都会漏掉。在回答"GBS 有没有用"之前，必须先用修好的仪器重测。成本分钟级。
- **Phase 2 顺序调整**：E2.4（ρ 稳健化）提到 E2.1（GBM 网格）之前。E1.2 证据显示 GBM 容量已接近 base 特征的信息上限（gbm-base ≈ ridge-extended），E2.1 头部空间有限；而 ρ=1 失效模式（首轮真机 4/5 折选纯 GBS、测试全负）是真机链路已暴露的真实风险。

### 仪器精度坐标

20 折下 ΔIC 的 95% CI 半宽 ≈ **±0.015**（E1.2 实测）。增量 ≥ 0.015–0.02 才可判定；更小的效应停留在"测不准"区间——这是当前 3 年数据的规模天花板，也是 E1.4 数据外求的价值所在。

### 逐项预期效果

| 实验 | 先验预期 | 各情景的含义 |
|---|---|---|
| **G0 真机复测** | 最可能：Q1H–Q4H 增量仍在 ±0.015 内不显著；Q4H（GBM 读出）IC 接近 C3 水平 | A. 增量 ≈0 且 CI 收紧 → 零结果可信度大增，Phase 3 转为"把零结果钉死"；B. 某级出现 ≥0.02 显著增量 → 全面转向 Phase 3 深挖；C. extended 基座下 GBS 相对新 C2 的差距缩小 → 说明首轮部分负差来自特征缺失而非 GBS 本身 |
| **E2.4 ρ 稳健化** | 测试期 IC 方差下降、极端负折减少；均值改善有限 | 价值在"保险丝"而非"增益"；若 bootstrap 约束下 ρ 系统性选低 → 本身是 GBS 贡献弱的独立证据 |
| **E2.1 GBM 网格** | +0.005~0.01 IC 量级，可能不显著 | 若网格内最好/最差差异 < CI 半宽 → 读出侧到顶，果断停止调参 |
| **E3.2 shots 爬坡（200k→5M）** | IC 曲线在 200k–500k 即进入平台 | 依据：200k 时边际统计离散度已仅 0.7%，词表早已收敛；预期产出是"样本量不是瓶颈"的实证，并把 5M 全量正式化 |
| **E3.1 b 标定 / E3.3 映射 / E3.4 编码网格** | IC 差异大概率 < 噪声底 | 价值是完备性：冻结配置时排除"没调好"的质疑；若某项出现超噪声差异，反而是重要线索 |
| **E4.1 诊断一（真机 vs 仿真分布）** | 边际一致、二阶有可见差距 | 分布有显著差距而 IC 无差距 → "联合结构对本任务无增量"的铁证；分布都一致 → 仿真可替代真机做后续开发，本身是有价值的工程结论 |
| **E4.3 推断层（BH 族控制）** | 现有"显著"结果可能部分降级 | E1.2 的 +0.0175 是两两 CI，纳入全族多重比较后下界可能触 0——届时如实报告，这是 §7.4 的本职 |

### 整体诚实预期

基于现有证据（置换/匹配对照全空、信息有界性论证、经典侧最佳 IC 也仅在 0 附近），"真机 GBS 在收益点预测上产生稳健增量"的先验**偏低**。本路线最可能交付的价值依次为：

1. **一个统计上有牙齿的判定**（无论正负）——方案书 §7.5 规定的交付物；
2. **一个被修好的经典基线**（extended 特征 + P1 协议 + 稳健 ρ）——无论 GBS 结论如何都可交付的增量；
3. 小概率但高价值：extended 基座上 GBS 检出真实增量。

探索性候选（不进正式假设族，避免过拟合）：E1.1 显示市场状态特征贡献最大，提示**状态条件化预测/混合**（高波动状态下收缩模型输出）可能有独立收益；Phase 2 后用 valid 期做一次低成本探查再决定是否立项。

### 时间预算

G0 约 0.5 天；Phase 2 约 2 天；Phase 3 约 2 天（E3.6 条件触发另计 2–3 天）；Phase 4 约 2 天；Phase 5 综合与报告 2–3 天。

## 防过拟合纪律（方案书 §7.2/§7.4）

1. E1.2 确定滚动协议后立即冻结并版本化；后续任何实验不得再动协议。
2. 全部超参（特征族、读出、ρ、ν、编码、优化器）只在 train/valid 内选择，测试期只跑一次。
3. 同一测试期上的全部配置对照纳入同一 BH 检验族；显著性水平 5% 测试前锁定。
4. 负结果与正结果同等如实写入报告（§7.5）；任何一层假设未通过即停止扩大该方向复杂度。
