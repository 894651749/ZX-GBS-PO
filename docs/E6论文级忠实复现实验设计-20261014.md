## 1. 总体目标

把九章论文（arXiv:2506.19707）的特征构造原版搬到本项目，替换现行"1/2/3 阶标量查表"构造，在冻结的 P1 协议（train 1y / valid 3m / test 1m，purge 5d，embargo 2d，20 折）上回答一个终审问题：

> **二阶/高阶 GBS 特征无效，是构造问题还是任务问题？**

- 若论文原版构造有效 → 此前负结论是构造失真所致，Q4 终定义改写；
- 若仍无效 → 任务信号天花板实锤，GBS 线以"26 经典 + 边际"收口，转向方案书 §6.1 风险先验方向。

## 2. 论文原版的四个要素（复现清单）

| # | 要素 | 论文做法 | 本项目映射 |
|---|---|---|---|
| 1 | 特征分组 | 16 特征/组，组内每特征占一个空间模；奇偶组分别落 A/B 时间分区（消碰撞） | 26 维 = **A 组（特征 0–15，16 模）+ B 组（特征 16–25，10 模）** |
| 2 | 分区内量化 | 特征值量化到分区内 bin（A 区 256 档、B 区 255 档） | 同左；encoder 需增加"分组分区量化"变体 |
| 3 | 联合 pattern 直方图 | 每行在全部 shots 上统计其寻址子集的 2^16 种点击 pattern 频率 | A 组 65536 种、B 组 1024 种 pattern |
| 4 | 基选择 + 读出 | 用训练样本（n1=1000 张图）选 top-N 高频 pattern（N=3000/组）；计数→归一化→sigmoid→拼接原始特征→线性读出 | A 组 top-3000 + B 组全 1024 ≈ **4000 维**，拼接 26 维经典，ridge 读出（P1 主线口径） |

## 3. 阶段划分

### 阶段 0：实现 + 可行性基准（约半天，纯工程）

- 新模块 `src/qgbs/gbs/pattern_service.py`：位打包列存储 + 按行投影 + bincount 的直方图引擎
- encoder 增加分组 A/B 分区量化变体
- 单元测试：合成小数据对照暴力实现，验证直方图逐比特正确
- **性能基准**：单行投影+bincount 的实测耗时/内存 → 决定 shots 档位（1M 或 5M）与并行方案
- 产出：**可行性判决**。这是最大工程风险点——20 折 × 每折约 23 万行 ≈ 470 万次直方图，必须实测确认落在小时级而非天级

### 阶段 1：单折小规模验证（约 2–4 小时）

- 取一个折、行子集（约 2 万行）、1M shots 端到端跑通
- 检查项：
  - 特征矩阵稀疏度/分布是否合理
  - 基选择流程无泄漏（**只用该折 train 行**选基）
  - 与既有边际特征的相关结构
- 产出：**继续/终止判决**；若耗时超标，降 shots 或砍 B 组先保 A 组

### 阶段 2：正式全量实验（计算数小时至 overnight）

- 新配置：建议命名 `q4paper_full_hardware_p1ext.yaml`
- 特征：26 经典 + pattern 指纹约 4000 维；ridge 读出（P1 主线口径）
- 全 20 折、块 bootstrap（2000/5/42）CI
- 对照：**C2**（26+ridge，IC -0.0163）、**Q1**（26+边际+ridge，IC +0.0169，Q1−C2=+0.0332）
- 产出：主结果——pattern 特征相对 C2、相对 Q1 的 ΔIC 及 CI

### 阶段 3：归因与消融（约半天，部分可与阶段 2 并行准备）

- **纯 pattern 特征**（对应论文 GELM-only）vs 纯经典——pattern 特征自身携带多少信号
- **破坏式对照**：采样流模式列置换打乱（保留边际、摧毁量子关联结构）→ 打乱后性能不变说明有效成分仍是边际/寻址；下降则说明关联结构首次被真正利用
- **shots 稳健性**：1M vs 5M 词表/指标漂移
- **GBM 口径对比**（此前承诺的筛选后 GBM 对比在此一并补上）

### 阶段 4：判定与文档（约 1–2 小时）

预先承诺的判定规则（跑数前冻结）：

- 若 （经典+pattern）−C2 的 CI 不含零 **且优于 Q1−C2（+0.0332）** → 构造问题实锤，Q4 终定义改写为 pattern 指纹口径，后续补 E4.3 推断层
- 若 ≤ Q1 水平或不显著 → **任务信号天花板实锤**，GBS 线以"26 经典 + 边际"收口，转向 §6.1 风险先验方向
- 更新 `docs/方案进度总结-20261013.md` 与调研文档
