## 1. 一句话结论

**真机 GBS 链路已完整落地并跑通 Q1–Q4 全阶梯；在修复统计仪器（20 折协议）和输入特征（extended）后，真机 GBS 相对经典基线未检出可判定的增量（分辨率 ±0.015），其中二阶联合与高阶通道的增量上界已被压到无业务意义的量级（±0.0035 / ±0.0014）。** 首轮"GBS 大幅落后经典"的结论被证明主要是特征缺失造成的假象，已在复测中纠正。

## 4. 核心实验结果

### 4.1 首轮真机判定（P0 协议 5 折 + base 特征）——已被 G0 取代

H1–H4 均不成立，且 Q 系全面落后于 C2/C3。**事后证明该结论受低功效仪器（5 折）与特征缺失双重污染，仅作历史记录。**

## 5. 当前结论（三条）

1. **真机 GBS 相对经典基线无可检测增量**（当前分辨率 ±0.015）。首轮"显著落后"是特征缺失假象，复测后差距消失、方向转正但不显著。
2. **二阶联合与高阶通道无业务量级增量**：上界 ±0.0035/±0.0014，叠加置换诊断（+0.0002）与匹配对照（C5 差距不显著），"GBS 联合结构对本任务收益预测无增量"已是高质量负证据。
3. **GBS 特征对 GBM 读出是负贡献**（Q4H − C3base 显著为负），且 ρ 选择在 20 折上持续不稳定（[1,1,1,1,0,1,0.5,...]）——当前 GBS 特征集接入非线性读出的方式是负担而非资产。

## 6. 启发与方法论经验

1. **功效是第一瓶颈**：同一效应 5 折漏检、20 折显著。所有历史"无差异"结论在更换协议前都只能是初步的。
2. **信息与提取机制可替代**：gbm-base ≈ ridge-extended。新提取机制（含 GBS）的价值上界 = 输入中尚未被现有机制榨出的信息。调机制不如补信息。
3. **组合指标与 IC 背离**：IC 为负但 Sharpe 2.2+ 是市场暴露收益（cap 约束下 ~10 只顶格 + 2024–25 行情），不是选股技能；评估模型以 IC/ICIR 为准，组合层债务（占位成本、weight_cap 角点解）待还。
4. **大盘龙头方向可预测性更高**（pool29 dir_acc 0.50–0.52）：信号可能随市值分层，留作后续诊断线索。
5. **市场状态特征贡献最大**：提示状态条件化预测/混合的候选方向（探索性，不进正式假设族）。
