## 1. 实验要回答的问题

在 26 维经典特征 + 真机 GBS 的管线中，**二阶/高阶特征无效究竟是"构造问题"还是"任务问题"**？

- 若按九章论文（arXiv:2506.19707）原版构造的联合 pattern 指纹特征有效 → 此前负结论是构造失真所致，Q4 终定义改写；
- 若仍无效 → 任务信号天花板实锤，GBS 线以"26 经典 + 边际（Q1）"收口。

## 2. 实验设置

**构造（论文四要素忠实复现）**：26 维特征分两组——A 组（特征 0–15 → 16 空间模，时间模 0–255，256 档）+ B 组（特征 16–25 → 10 空间模，时间模 256–510，255 档），A/B 分区消除寻址碰撞；每行在 **1M shots** 真机采样流上统计其寻址子集（16+10 模）的**联合点击 pattern 频率直方图**；基选择用该折 train 内 1000 行（seed=42）取 A 组 top-3000 + B 组全 1024 ≈ **4024 维**；归一化 + sigmoid。

**协议**：P1 冻结协议——train 1 年 / valid 3 月 / test 1 月，purge 5 交易日、embargo 2 交易日，**20 折滚动样本外**（首测 2024-04-10，末测 2025-12-09，与官方口径逐字核对一致）；ridge 读出（α∈{0.1,1,10}，valid 择优）。

**双臂设计**（特征矩阵共享，一次计算）：

| 臂 | 构造 | 回答的问题 |
|---|---|---|
| **臂 A（论文忠实臂）** | 26 经典 + 4024 pattern 特征**全量拼接** + ridge | 终审：构造问题 vs 任务问题（与论文 GRVFL 配方对齐） |
| **臂 B（择优拼接臂）** | 4024 维先做监督筛选（valid rank IC 降序贪心、\|corr\|≥0.8 去冗、K∈{10,25,50,100,200} valid 择优），再与 26 经典拼接 | "GBS 特征组合调优"路线是否优于全量拼接 |

**运行环境**：公司服务器（64 进程），每折约 12 分钟；全程只用 train/valid 做选择，test 一次性使用。

## 3. 运行与数据完整性

- 20 个正式折全部完成，`fold_results.jsonl` 20 行完整；
- 脚本在一个**协议外**的第 21 折（test 2025-12-10~12-31，半月尾段）崩溃（退化窗口 IC 计算类型错误），不影响任何正式折；`summary.json` 未生成，已在本地依据 fold_results.jsonl + 官方参照系重建；
- 口径复核：用官方 C2/Q1 的逐日 IC 重建折均值，与官方值逐位吻合（C2 −0.0163、Q1 +0.0169、Q1−C2 +0.0332），证明对比口径正确。

## 4. 结果

### 4.1 主结果（20 折 test rank IC）

| 指标 | 臂 A（全量拼接） | 臂 B（筛选拼接） |
|---|---|---|
| test IC 均值 | **+0.0145** | +0.0043 |
| 正折比 | 60% | 50% |
| 折间 std | 0.0263 | 0.0345 |
| valid IC 均值 | +0.0161（85% 正） | +0.0097（65% 正） |

### 4.2 与官方参照系的配对对比（折级配对，20 折，bootstrap 20000 次）

| 对比 | Δ IC | 折级 95% CI | 正折比 |
|---|---|---|---|
| **臂 A − C2** | **+0.0308** | [-0.0081, +0.0676] | 70% |
| **臂 A − Q1** | **−0.0024** | **[-0.0291, +0.0223]** | 65% |
| 臂 B − C2 | +0.0206 | [-0.0200, +0.0588] | 70% |
| Q1 − C2（口径复核） | +0.0332 | [+0.0108, +0.0549] | 75% |

参照：C2（26+ridge）IC −0.0163；Q1（26+真机边际+ridge）IC +0.0169；Q1−C2 = +0.0332（官方逐日口径 CI [+0.0183, +0.0481]，显著）。

### 4.3 值得记录的细节

- 臂 B 的 K 网格上限 200 在 **16/20 折**被选中——筛选器几乎总是"想要更多特征"，valid 排序对 test 无预测力；
- 臂 A valid IC（+0.0161，85% 正）与 test IC（+0.0145）一致，全量拼接本身没有明显的 valid→test 衰减；
- 臂 A 折间形态与 Q1 历史形态相似（正负折分布接近），提示两臂捕捉的是同源信号。

## 5. 判定（按设计文档预冻结规则）

判定规则：**若 臂A−C2 的 CI 不含零且优于 Q1−C2（+0.0332）→ 构造问题实锤；若 ≤ Q1 水平 → 任务天花板实锤**。

实测：臂A−Q1 = −0.0024，CI 对称跨零 —— **统计打平**。触发第二条：

1. **"构造问题"假设被否决**：论文原版构造（完整联合指纹、输入条件化基选择、A/B 分区消碰撞、1M shots）下，二阶/高阶依然没有超过边际特征。三条独立路径——Q1 边际（+0.0332 vs C2）、C4 经典分位数展开（与 Q1 打平）、论文级 pattern 指纹（臂A−C2 点估计 +0.0308）——**收敛到同一个量级**：GBS 特征对本任务的可兑现价值全部集中在边际（分位数升维）层面；
2. **筛选路线亦不成立**：臂 B 显著差于臂 A，与 E5 筛选零结果互证——二阶/高阶中不存在"个体强而稳定"的特征，valid 上的组合调优只是过拟合验证集；
3. **最终交付形态确认**：**Q4 终定义 = 26 经典 + 真机 GBS 边际特征（Q1）**，H1 阳性（+0.0332、归因条款通过）为项目核心交付结论。

## 6. 口径限制（诚实声明）

- 折级配对 bootstrap（20 点）比官方逐日块 bootstrap 保守——臂A−C2 折级 CI 含零，而同等点估计的 Q1−C2 官方口径显著；臂 A 未保存逐日 IC，无法补官方口径 CI（判定规则的关键对比是臂A vs Q1，打平结论不受口径影响）；
- ridge 单读出口径；GBM 口径、列置换对照、5M shots 稳健性为设计文档阶段 3 的可选消融，在打平结论下边际价值低，未执行；
- 全部结论限于收益预测任务与当前数据（2023-01~2025-12、zz800 池、200k/1M shots 真机采样流）；"GBS 二阶结构在风险先验方向（波动率/相似性，方案书 §6.1）可能有效"不在本次判决范围内。
