## 1. E7：指标升级（Sharpe 口径审计 + IR + Calmar）

### 1.1 背景

客户验收框架（POC §六）：信号层 = rank IC 增量 ≥ +0.015 且 CI 下界 > 0；组合层 = **Sharpe 提升 ≥6%，或 IR 提升 x%，或 Calmar 提升 x%，三者满足其一且其余两项不得显著负**。IR/Calmar 的具体阈值 POC 文档留白（"待组合层口径确认后给出"）——E7 回填后用 Q1 实际提升幅度反推建议阈值，把谈判主动权拿在手里。

### 1.2 待办步骤

**E7.1a 现有口径审计（先行，带修正）**
- 现状疑点：现有 `annual_return=0.958 / annual_volatility=0.353 / Sharpe=2.08` 三者不自洽（0.958/0.353≈2.71≠2.08），年化口径与客户文档公式不一致；
- 动作：按客户文档统一——日频 f=252；收益年化、波动率年化乘 √252；Sharpe = (年化收益 − Rf)/年化波动率；明确算术/复合口径并对齐文档公式；
- 参数化：Rf 作为配置参数，**默认 0 并在报告声明**（待客户确认后切换，见 §4 待确认清单）。

**E7.1b 实现 IR 与 Calmar**
- **IR**：基准 = 000906.SH（中证 800，zz800 池天然基准，`data_store/market_sector_factor.csv` 已覆盖全区间）；逐日主动超额 = 组合日收益 − 基准日收益；IR = 年化主动超额均值 / 年化跟踪误差（×√252）；
- **Calmar** = 年化收益率 / MDD；MDD 在 20 折 test 段拼接的全样本外净值曲线上计算（现行拼接口径，报告声明）；

## 2. E8：GBS 风险先验（二阶/高阶特征的风险引擎落点）

### 2.1 动机与定位

- E6 已终审：在**收益预测**（alpha 引擎）上，二阶/高阶特征两条构造路径（低阶标量、论文级 pattern 指纹）均不超过边际特征——该方向在收益任务上关闭；
- 但组合优化有两个引擎：alpha（往哪走）+ 风险（哪里路滑）。协方差矩阵 Σ **本身就是二阶对象**，GBS 装置最独特的物理资源（模式间量子关联）在金融里的天然对应物是**资产间关联**；
- 方案书 §6.1 明文预留"GBS 风险先验（条件波动率/相似性）"分支；POC 文档 §五方向 4 已向客户预告。**不偏离方案书，管线架构不变**。

### 2.2 机制设计（增强，非替换）

Ledoit-Wolf 的现行做法：`Σ_LW = δ·Σ_样本 + (1−δ)·常相关目标`（无信息先验：假设所有股票相关性相同）。

E8 的做法：**把收缩目标从无信息的常相关矩阵，换成 GBS 量子关联给出的时变先验矩阵**：

```
Σ_E8 = δ·Σ_样本 + (1−δ)·Σ_GBS先验      （δ 在验证期择优；δ→1 时自动退回经典 LW）
```

**LW 框架全部保留**（对称化、负特征值截断、尺度校准三步处理原样）；δ 由验证期数据决定——GBS 先验若无信息，δ 学成 1，下界锁死在经典基线上。

**Σ_GBS先验 的构造**（复用现有组件）：

1. 每只股票 i 在每个调仓日 t，其 26 维特征经（各折 train 窗拟合后冻结的）寻址器得到 26 个模式地址集合 A_i(t)；
2. 定义量子相似性（主口径）：K(i,j,t) = A_i(t) 与 A_j(t) 两组地址在真机相关矩阵 ρ̂ 上的**跨组平均相关**；
3. 矩阵化实现：构造 800×8176 地址指示矩阵 U（每行 26 个 1），则 K = U·ρ̂·Uᵀ/26² —— 每调仓日一次矩阵乘（约 100 GFLOP，数秒），全 20 折约 420 个调仓日，计算量数十分钟级，**无需服务器**；
4. Σ_GBS先验 = D·K·D（D = 各股已实现波动率对角阵），经三步处理（对称化/PSD 投影/尺度校准）后进入混合。

**卖点**：常相关目标是静态、无信息的；GBS 先验是**时变的**（地址随特征每日变化）且携带量子关联结构。

### 2.3 对照设计（同协议配对）

| 配置 | alpha 引擎 | 风险引擎 | 目的 |
|---|---|---|---|
| R0 | Q1（26+边际+ridge，固定不动） | 经典 LW（常相关目标） | 基线 |
| **R1** | 同 R0 | **Σ_样本 收缩到 GBS 先验** | 主检验 |
| R2 | 同 R0 | Σ_样本 收缩到**随机先验**（随机 PSD 矩阵，同混合结构同 δ 网格） | 归因对照：排除"多收缩一次"本身的效果 |
| R3' | 同 R0 | Σ_样本 收缩到**静态 GBS 先验**（时间平均版 K） | 消融：时变性的贡献 |

### 2.4 判定规则（预冻结）

- **主判定 H5**：R1 相对 R0，组合层三指标（Sharpe/IR/Calmar）至少一项的配对 bootstrap 95% CI 下界 > 0，且其余两项不显著为负（与验收口径同构）；
- **归因条款**：R1 须显著优于 R2（随机先验），否则增量不能归因于 GBS 结构；
- **辅助指标**：组合层面已实现波动率（realized vol）与预测波动率的吻合度、换手变化；
- **停止规则**：若 R1≈R2（随机先验打平），风险先验方向如实记负结论，回到 LW 交付。

### 2.5 防泄漏

- ρ̂ 词表仍来自冻结的真机 200k shots（与金融数据无关，天然无泄漏）；
- 寻址器各折仅用 train 窗拟合后冻结；δ 与 (κ,τ,γ) 一样走训练/验证期选择、测试期冻结；
- test 一次性使用。

### 2.6 阶段划分与耗时

| 阶段 | 内容 | 耗时 |
|---|---|---|
| E8.1 | 实现（U·ρ̂·Uᵀ 引擎 + 混合风险模型 + R2/R3' 对照）+ 单元测试 + 单折验证 | ~1 天 |
| E8.2 | 全 20 折正式实验（本地可跑，矩阵乘为主） | 数小时 |
| E8.3 | 归因汇总 + H5 判定 + 文档更新 | 半天 |

### 2.7 备选分支（本设计暂不实施，视 E8.2 结果决定）

机制 B：GBS 特征预测未来已实现波动率（波动率聚类是金融中最强可预测现象）→ 逐股 vol 预测 + 相关先验合成 Σ。若 E8 主线（机制 A）阴性但波动率预测探针有信号，再启用。
